0. TL;DR (PD 1분 요약)

  • 귀결: 200층 보스 원본 HP 114억 = "유저가 프레스티지로 뚫는 벽"으로 확정됨. 원본 수치를 낮추는 대신 플레이어 축에 성장 여력을 추가한다.
  • 원본 자산 결론: 프레스티지/파라곤 테이블은 원본에 존재하지 않음. 단 guardian_stone_enhance_point(char_main 필드, "초월 던전에서 획득하는 수호석 강화 포인트") 개념이 유일한 유사 축 → PP 명명·획득 원천 아이디어만 재활용, 나머지는 신규 설계.
  • 권장 구조: 디아블로 3 축소판 C안 (3탭 × 10항목, 항목당 소프트캡 5단계 후 diminishing 무한성장). 1인 제작 기준 가장 현실적.
  • 해금: 100층 "초월자" 마일스톤에서 오픈 (초월모드 스토리 정합성).
  • 역산: DPS 1M·5분 클리어 가정 시 200층 보스 격파에 약 140 PP 필요 → 100층 도달 유저 기준 방치 약 7~10일분.
  • Sprint 02~04 기간 소프트 리셋 없음. 단 슬롯 구조는 permanent / seasonal 2채널로 미리 분리해 Sprint 05+ 시즌 도입 대비.

1. 목적·귀결

1.1 왜 프레스티지가 필요한가 (Q1 C안 정리)

transcendent_reward_draft.md §7.2 에서 PD 승인된 C안은 다음을 확정했다:

  • 원본 data_transcendent_stage.boss_spawn_hp_amount 는 0% 수정. 즉 200층 보스 HP ≈ 114억은 고정상수.
  • 대신 플레이어의 영구 성장 축을 신설해, 같은 보스 HP를 "자본 축적으로 뚫는 벽"으로 재해석.
  • 2019 원본은 4인 파티·풀 액티브 기준이므로 싱글 자동전투 DPS는 약 −40%로 예상(§2.2). 이 갭을 장비·레벨만으로 메우면 100층 도달 후 성장 상한(플래토)이 바로 와서 방치형 게임의 생명인 "오늘도 돌아올 이유"가 꺾인다.
  • 따라서 장비 축(유한: Mythic까지 드랍)과 병렬로 무한 성장 가능한 PP 축이 필요하다.

1.2 스코프 경계

포함 (본 스펙):

  • DPS 성장 축 제공 (공격력/치명/방어/드롭률/골드·EXP 증폭 등)
  • 무한 성장 곡선 (소프트캡 + diminishing)
  • 일일 리듬 훅 (24h 방치 → PP 누적)
  • 해금 플로우, UI 컨셉, 영구/시즌 슬롯 구조

불포함 (Sprint 02 내 금지):

  • 직업 변경·스킬 교체 (별도 "승천/클래스 변경" 축, Sprint 07+ 유예)
  • 스킬 트리 리워크 (기존 SkillInfo.xml은 건드리지 않음)
  • Ancestral/Sacred 같은 장비 세컨더리 축 신설 (Sprint 04 이후)

2. 진입 조건

2.1 해금 시점

  • 해금 층: 100층 "초월자" 마일스톤 클리어 (transcendent_reward_draft.md §5 대응)
  • 근거:
    • 1~99층은 "서사 확장 + 장비 파밍" 구간으로 유지 → 초반 유저에게 시스템 인지부하 최소화.
    • 100층 도달은 "이제 본격 엔드게임" 신호. 디아블로 3의 토르먼트 진입과 동일 구조.
    • 100층 도달 평균 시간은 transcendent_reward_draft.md §2.2 추정으로 첫 주 내 비교적 자연스럽게 달성 (방치 포함).
  • 대안: 레벨 기반 해금(예: 캐릭터 Lv 70) — 기각. 층 기반 해금이 초월모드와 직관적 정합.

3. 프레스티지 포인트 (PP) 획득

3.1 획득 원천 5가지

원천설명일일 비중(%) 권장
(A) 층 첫 클리어N층 최초 클리어 시 1회 PP 보상 (층수 ↑ 증가)20%
(B) 보스 처치 누적10층 단위 보스 누적 처치 (반복 가능)15%
(C) 방치 누적 (시간당 PP)최고 도달층 기반 시간당 PP 드립50%
(D) 마일스톤100/150/200층 등 이정표 도달 1회10%
(E) 일일 퀘스트 / 광고 보상일 1회 광고 시청 × 2, 일일 퀘스트 완료5%

비중 해석: 방치형 게임의 절반 이상이 오프라인 드립에서 나와야 "안 켜도 자란다"는 방치 철학 유지. 나머지는 "접속해서 층 깨면 가속" 보상.

3.2 원천별 수식 (잠정)

  • (A) 층 첫 클리어 PP: floor(1 + stage^1.2 / 20)
    • 100층 첫클 = floor(1 + 251/20) = 13 PP
    • 150층 첫클 = floor(1 + 444/20) = 23 PP
    • 200층 첫클 = floor(1 + 660/20) = 34 PP
    • 1~99층 소급: 총 약 Σ floor(1+n^1.2/20), n=1..99 ≈ 520 PP (해금 즉시 선지급)
  • (B) 보스 반복: 10층 단위 보스 1회 = floor(stage/20) PP, 쿨다운 없음 (그냥 재입장 반복)
    • 100층 보스 반복 = 5 PP/회
  • (C) 방치 드립 (시간당): maxClearedStage × 0.05 PP/hour, 오프라인 캡 24h (광고로 48h 확장)
    • 100층 유저 10h 방치 = 50 PP
    • 100층 유저 24h 방치 = 120 PP
    • 150층 유저 24h 방치 = 180 PP
  • (D) 마일스톤: 100층=+50 / 120층=+50 / 150층=+80 / 180층=+100 / 200층=+150 PP (1회성)
  • (E) 일일 퀘스트·광고: 일일 퀘스트 3개 완료 = +10 PP, 광고 2회 = +10 PP → 하루 최대 +20 PP

3.3 일일 획득 예시 (100층 도달 유저, 10시간 방치 기준)

원천PP
방치 10h50
접속 후 보스 5회 반복25
신규 층 2개 클리어 (101·102층)27

일일 20 PP ~ 150 PP 사이가 정상 범위. 소프트캡 진입 구간(항목당 50 PP)을 1.5~3일 단위로 하나씩 찍는 리듬.

4. 투자 축 — 3안 병기

4.1 A안 (디아블로 3 평면 4탭, 과하게 큼)

  • 4탭: Core / Offense / Defense / Utility
  • 각 탭 25항목 × 무한 레벨 (항목당 소프트캡 50 PP)
  • 제작량: 항목 100개 × 스탯식 = 100개 수식 설계 + UI 100슬롯
  • 재미: "어디 찍을지" 고민이 많아 고수가 깊이 즐김
  • 1인 제작 평가: ❌ Sprint 02 2주 안에 100항목 수식 검증 불가능. Unity UI도 100슬롯은 인지부하 초과.

4.2 B안 (디아블로 4 노드 그래프)

  • 경로 의존 트리 + Legendary 노드 + Glyph 슬롯
  • 제작량: 노드 그래프 에디터 자체가 Sprint 1개 분량. 이후 노드 80~120개 설계.
  • 재미: 빌드 선택권 폭발, 리롤·변경 이슈 발생 → UX 복잡도 급증
  • 1인 제작 평가: ❌❌ 노드 그래프 에디터 Unity 툴 자체를 만들어야 한다. 거의 게임 하나 분량. Sprint 02 범위에 불가.

4.3 C안 (축소판, 권장)

  • 3탭 × 10항목 = 30항목.
    • Offense (공격 계열): 공격력%, 치명타율, 치명타 피해, 공속, 스킬쿨 감소, 관통률, 원소 피해, 보스 피해, 다굴 피해, 장비 옵션 증폭
    • Defense (생존 계열): 체력%, 방어력%, 회피율, 받는 피해 감소, HP 재생, 흡혈, 받는 치명 확률 감소, 소환수 체력, 영웅 부활 횟수, 수호자 공격력(펫)
    • Utility (경제·드롭 계열): 드롭률, 골드 획득량, EXP 획득량, 층 입장권 할인, 방치 수익 +, 광고 보너스 +, 마일스톤 보상 +, 오프라인 캡 시간, PP 획득량, 수호석 포인트 확률
  • 항목당 곡선:
    • Lv 1~5 (소프트캡 전): 1 PP당 +0.5% (또는 해당 스탯 단위)
    • Lv 5 이후: diminishing, bonus = 2.5% + 0.5% × log2(1 + (pp-5)/5) → 1 PP당 0.1%~0.25% 수준으로 감소
    • 최대값 없음 (무한 성장)
  • 제작량: 항목 30개 × 수식 = 수식 약 10종 (스탯 계열 재사용) × 30 슬롯 UI
  • 재미: "한 탭 몰빵 vs 분산" 고민. 소프트캡 때문에 "찍고 다음 항목으로 넘어갈까" 자연스러운 갈등.
  • 1인 제작 평가: ✅ 2주 W1(수치 TSV) + W2(30슬롯 프로토) 커버 가능.

4.4 권장: C안

이하 수치·UI는 C안 기준. A안·B안으로 결정 시 §5·§7은 재작성 필요.

5. 수치 곡선 (C안 기준)

5.1 단일 항목 PP 효율 (공격력% 예시)

f(pp) = 0.5% × min(pp, 5)                       // 소프트캡 전 선형
      + [pp > 5 이면 2.5% × log2(1 + (pp-5)/5)]  // 이후 로그 증가
PP 투자공격력 보너스한계 효율
5+2.50%+0.50%/pp
10+4.88%+0.30%/pp 평균
25+8.12%+0.20%/pp
50+11.02%+0.15%/pp
100+14.17%+0.09%/pp
200+17.31%+0.05%/pp

→ "처음 5포인트는 엄청 짜릿, 다음 5~25는 쓸만함, 50 이후는 '한 번 더 찍을까' 망설여지는 diminishing". 디아블로 감성 유지.

5.2 총 빌드 파워 (예시: 공격·치명·보스·드롭 4항목 분산)

치명타 피해 같은 곱연산 스탯이 핵심 기여. 4항목 분산 기준 500 PP 찍어 DPS 1.85배.

5.3 200층 보스 격파 역산 (PD 요구 §5)

전제:

  • 100층 기준 유저 평균 DPS = 1,000,000 (1M)
  • 200층 보스 HP = 114억 = 11,400,000,000
  • 원하는 클리어 시간 = 5분 = 300초
  • 필요 DPS = 11,400,000,000 / 300 = 38M DPS
  • 현재 DPS 대비 배수 = 38M / 1M = 38배 필요

이 38배 중:

  • 장비 성장 기여 (100→200층 구간 Mythic 드랍·수호석 업·옵션 리롤) ≈ ~15배 가정 (추후 장비 스펙에서 검증 필요)
  • 프레스티지 기여 필요 = 38 / 15 ≈ 2.5배

공격·치명률·치명피·보스 4항목 기준 2.5배를 만들려면 역산:

  • 1.20 × 1.12 × 1.50 × 1.20 ≈ 2.42 → 근접
  • 각 항목 약 150 PP 씩 필요 → 총 600 PP 필요
  • 보수적으로 공격·치피에 더 투자, 총 ~700 PP 잡으면 안정권

추가 여유 잡아 900 PP = 기본 분산 투자로 200층 격파 가능 권장치.

실효 필요 PP를 §5.3 역산으로 단순화하여 PD 커뮤니케이션 라인:

"200층 5분 격파 필요 PP ≈ 700~900 PP. 보스 피해 집중시 ≤ 600 PP 가능."

5.4 방치 며칠분인가

100층 유저 일일 획득 122 PP(§3.3) 기준:

  • 700 PP = 5.7일
  • 900 PP = 7.4일
  • 역산 한 줄 답: 200층 격파에 필요한 프레스티지 적립은 방치 약 7~10일

150층 유저(일일 180+ PP) 기준 4~5일로 단축. 풀 카지노형 가속 기대치에 부합.

6. 소프트 리셋 (Rebirth) 정책

6.1 Sprint 02~04 기간

  • 소프트 리셋 없음. Q5 귀결 = 시즌 리셋은 Sprint 05+ 유예.
  • 유저는 PP 투자를 "영구 자산"으로 인식 → 장기 복귀 동기 유지.

6.2 Sprint 05+ 시즌 도입 대비 구조

핵심 설계 결정: PP 슬롯을 2채널로 분리한다.

UserPrestige {
    permanentPP: long            // 영구 채널 (Sprint 02~)
    seasonalPP: long             // 시즌 채널 (Sprint 05~)
    permanentAllocation: Map<NodeId, int>
    seasonalAllocation: Map<NodeId, int>
}
