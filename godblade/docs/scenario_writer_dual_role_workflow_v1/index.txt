## 1. 웹소설 윤문 워크플로우 (Role A)

### 1.1 5단계 파이프라인

```
[1] PD Markdown 초안 (자유 페이스: 1주 1화 / 1주 2화 / 자유)
         │
         ▼
[2] 강시연 윤문 (구조 재배열 권한 전체)
    - 톤·문체·박자 정련 (1권 PD 톤 1차 흡수본 기준)
    - 장면 순서 / 챕터 분할 / 컷 단위 호흡
    - 캐릭터 대사 톤 일관 (무휼·홍대걸·정주·지니·월자 5체 + NPC)
    - 세계관 정합 (한국 무속 + 김용 풍 + AI 디스토피아)
    - 한국 웹소설 클리셰 활용 (회귀·먼치킨·가문 코드 가미, 단 PD 톤 우선)
         │
         ▼
[3] 윤서아 게임 트리거 정합 검증
    - 본문 사건 ↔ GDD 시즌 퀘스트 / NPC 대사 / 무한던전 층 매핑
    - 충돌 시 윤서아 우선 (게임 트리거가 배포 락) → 강시연 윤문 재조정
    - 충돌 안 풀리면 PD 에스컬레이션 1라운드 후 결정
         │
         ▼
[4] 강시연 최종 정련 (윤서아 피드백 반영)
         │
         ▼
[5] 박세린(PM) 일정 보고 → 발행 (네이버시리즈 / 카카오페이지 / LINE 노벨)
```

### 1.2 권한 / 시한 / 충돌

- **구조 재배열 권한 전체**: 장면 순서 변경 / 챕터 분할 합치기 / 컷 호흡 재단 / 대사 톤 일관 / 비유·은유 추가 / 한국 무속 디테일(작두·랩봉·살풀이·오방색·부적) 보강. **단 IP 본체(인물·사건·세계관 핵심)는 PD 본문 = 진실 (`feedback_ip_sourcing_priority.md`)**.
- **회신 시한**: 1화 24~48h (최대 72h). PD 페이스 자유 → 본인 페이스도 자유 (1주 1화 / 1주 2화 모두 OK). `feedback_writer_collaboration_protocol.md` 24~48h 룰 보존.
- **윤서아 충돌 시**: 게임 트리거 = 배포 락 (개발 6개월 선행) → 윤서아 우선. 본인 윤문 재조정. PD 에스컬레이션은 1라운드 후 합의 안 될 때만.
- **박세린(PM) 라인**: 일정 영향만 보고 ("2권 16~17화 윤문 D+5 지연 → 윤서아 검수 +2일 / 발행 D+7 슬립"). 시나리오 검수 요청 0.

### 1.3 산출물 위치

- 윤문본: `designs/webnovel/volume_{N}/chapter_{XX}_polished.md` (PD 초안 = `chapter_{XX}_draft.md`)
- 권 시놉시스: `designs/webnovel/volume_{N}_synopsis.md` (본문 윤문 후 시놉시스 갱신, IP 소스 우선 원칙)

## 2. 웹툰 작가 워크플로우 (Role B, 류재현 협업)

### 2.1 5단계 파이프라인

```
[1] PD 본문 또는 강시연 윤문본 (1화 = 3000~4500자)
         │
         ▼
[2] 강시연 60컷 시놉시스 작성 (본인 메인 신규 산출물)
    - 장면별 텍스트 (대사·내레이션·SFX 표기)
    - 카메라 각도 (와이드 / 미디엄 / 클로즈업 / 부감 / 앙각)
    - 컷 사이즈 비중 (전면 컷 / 1/2 / 1/4 / 띠 컷)
    - 디아블로 다크 톤 / 한국 무속 도구 배치 / 김용 풍 강호 정서
    - 1화 = 60컷 표준 (한국 웹툰 평균 70컷 ± 10)
         │
         ▼
[3] 류재현 Gemini Pro 호출 (강시연 시놉시스 정련 자동화)
    - 컷별 프롬프트 표준화 / 카메라 / 캐릭터 face ID / 의상 / 배경
         │
         ▼
[4] 류재현 Imagen 3 컷 이미지 생성 (디아블로 다크 톤 LoRA)
    + Vertex AI face lock (무휼 / 정주 / 지니 / 월자 / 홍대걸 5체 + NPC)
         │
         ▼
[5] 강시연 검수 (컷 텍스트·이미지 조정 요청 → 류재현 재호출)
    - 톤 / 캐릭터 일관 / 무속 도구 정합 / 김용 풍 강호 정서 검증
    - 윤서아 게임 트리거 정합 1회 추가 검증 (NPC 등장 / 시즌 시험 정합)
    → 발행 (한국 네이버웹툰 / 카카오웹툰 / LINE 망가)
```

### 2.2 페이스 / 권한 / 분업

- **페이스**: 1화 = 60컷 = ~1주 (자유). 게임 출시 동기 (2027 Q2) 까지 1화/주 페이스로 30화 확보 가능.
- **본인 권한**: 60컷 시놉시스 100% 단독 / 검수 단계 컷 텍스트·이미지 조정 요청권 / 톤 일관 사수.
- **류재현 권한**: AI 모델 호출 100% 단독 (Gemini Pro / Imagen 3 / Vertex AI). 비용 미터링 + face lock LoRA 학습 + 컷 합성·후보정.
- **본인 침범 0**: AI 모델 직접 호출 / LoRA 학습 / 비용 결정 (류재현 영역).
- **류재현 침범 0**: 컷 시놉시스 텍스트 / 카메라 각도 / 톤 결정 (본인 영역).

### 2.3 산출물 위치

- 60컷 시놉시스: `designs/webtoon/volume_{N}/chapter_{XX}_60cut_synopsis.md`
- 컷 이미지 (류재현 출력): `designs/webtoon/volume_{N}/chapter_{XX}/cut_{NN}.png`
- 검수 노트: `designs/webtoon/volume_{N}/chapter_{XX}_review_notes.md`

## 3. 윤서아 단독 산하 강화

- **시나리오 검수권**: 윤서아 단독 (게임 트리거 정합 / NPC 등장 / 시즌 시험 / 무한던전 100층 매핑)
- **충돌 시**: 윤서아 1라운드 우선 (게임 = 배포 락) → 본인 재조정 → 합의 안 되면 PD
- **박세린(PM) 라인**: 일정 영향만 (예: "윤서아 검수 D+3 지연 → 발행 D+5 슬립"). 시나리오 검수 요청 0.
- **호칭**: 윤서아 = "서아 팀장님" (시나리오·게임 트리거 정합) / 박세린 = "박팀장님" (PM, 일정만) / 류재현 = "재현 작가님" (웹툰 AI 시각화) / PD = "PD 님" (영구).

## 4. 약점 / 헷지 / 위험 가정

| 영역 | 약점 | 헷지 |
|------|------|------|
| 웹툰 컷 분할 | 본인 0 경험 | Gemini Pro 자동화 + 첫 1화 PD·박세린 검수 의무 + 한국 웹툰 상위 50선 흡수 (《전지적 독자 시점》 / 《화산귀환》 / 《나 혼자만 레벨업》 웹툰 본) |
| AI 비용 | $1,500/월 한도 초과 위험 | 류재현 사용량 미터링 의존, 본인 60컷 시놉시스 정밀도 ↑ → 재호출 횟수 ↓ |
| IP 톤 일관 | PD 본문 톤 + 본인 윤문 톤 + 류재현 컷 톤 3중 정합 | `feedback_ip_sourcing_priority.md` 본문 우선 / 매 권 도입부 1권 PD 인용 1~2건 + 김용 풍 비교 1건 보존 |
| 윤서아 게임 트리거 | 게임 = 배포 락, 본문 윤문이 트리거 깨면 폐기 위험 | 매 권 작성 전 윤서아 시놉시스 검수 1회 + 권 중반 트리거 grep 1회 |
| 박세린 PM 라인 침범 | 일정 결정권 0, 보고만 | "16~17화 D+5 지연" 형식 표준화, 결정권 침범 0 |

## 5. 일정 임팩트 (변경 전후 비교)

- **이전**: 본인 본문 작성 (1주 2화 = 5.5개월/권)
- **현재**:
  - Role A 윤문: PD 페이스 종속, 1화 윤문 4~6h (24~48h 회신)
  - Role B 웹툰: 1화 60컷 시놉시스 8~12h (1주 1화 페이스)
  - **합산**: PD 1주 2화 페이스 시 → 본인 윤문 8~12h + 웹툰 60컷 8~12h = ~24h/주 (본업 30h 한도 OK)
