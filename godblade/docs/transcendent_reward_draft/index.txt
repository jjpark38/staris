## 1. 목적

디아블로식 "한 층 더만…" 루프를 방치 리듬으로 재포장한다.
- **능동 플레이**: "이 층 막혔으니까 장비 맞추고 다시 간다" (하드코어 2~4시간/주말)
- **방치 플레이**: "오늘 뭐 드롭했지?" (로그·알림 5분/출퇴근)
두 리듬 모두 **드롭 희열**(디아블로 어픽스 판별의 쾌감)을 중심으로 설계한다.

## 2. 층수 진행 곡선 (1~200층)

### 2.1 원본 수치 재활용 전략

원본 `data_transcendent_stage` 29컬럼 중 **난이도 스케일링에 쓰이는 필드**는 다음 5개:

| 컬럼 | 역할 | 재활용 방침 |
|------|------|-------------|
| `monster_level` | 몬스터 레벨 | **그대로 재활용** (1~200 매핑 양호) |
| `recommend_level` | 권장 레벨 | **그대로 재활용** |
| `atk_ratio` | 몬스터 공격력 배율 | **그대로 재활용** |
| `def_ratio` | 몬스터 방어력 배율 | **그대로 재활용** |
| `boss_spawn_hp_amount` | 보스 HP (200층 ~114억) | **재조정 필요** — 싱글 방치형은 DPS 성장이 멀티 대비 느려 하드 벽이 됨 |

### 2.2 싱글+방치형에 맞춘 재조정 근거

원본은 **파티 4인 + 풀업 장비 + 액티브 조작** 전제. 싱글 방치형 전환 시:
- **DPS 기대값 하락**: 풀 액티브 대비 자동전투는 스킬 최적화 루프 손실, 체감 −40% DPS
- **시간 예산 축소**: 멀티 이벤트는 "30분 집중 레이드", 방치는 "1층 15초~3분" 단위
- **심리 곡선 필요**: 방치형은 "하루 1층 진전"이 최소 체감 목표 → 소프트 벽 간격 10층 권장

### 2.3 제안 곡선 (대안 2개)

**A안 (지수형, 디아블로 Torment 계단형)**
- 보스 HP: 원본 `boss_spawn_hp_amount` 그대로 (1층 ~1,000 → 200층 ~11,400,000,000)
- 장점: 원본 200층 그대로 수용, 임포트 재사용 100%
- 단점: 1인 방치형엔 과격. 100층 이후 DPS 없으면 "완전 정지" → 하드 벽
- **적합층**: 능동 플레이어(파밍충)에게는 완벽

**B안 (로그 보정, 방치형 재튜닝)**
- 보스 HP = `원본 × f(층)`, 여기서 `f(층) = clamp(0.5 + 층/200, 0.5, 1.0)`
- 즉 1~100층은 원본의 50~100%, 101~200층만 원본 그대로
- 장점: 초중반 진입 장벽 완화, "하루 3층 진전" 보장
- 단점: 원본 수치 수정 필요 → TranscendentStageSO 오버라이드 레이어 1개 추가

**C안 (추천, 하이브리드)** ← **PD에게 권장**
- 보스 HP는 A안 원본 유지하되, **플레이어 쪽에 무한 성장 축(프레스티지/파라곤)을 붙여** 벽을 스스로 뚫게 한다
- 원본 수정 0%, 방치 리듬은 성장 축에서 흡수
- 단점: 프레스티지 시스템 별도 설계 필요(본 문서 범위 밖, Sprint 02 예정)

### 2.4 예상 진행 구간 (C안 전제)

| 구간 | 층수 | 체감 단계 | 막힐 가능성 | 방치 보상 가치 |
|------|------|-----------|-------------|----------------|
| **저항** | 1~30 | "튜토리얼+적응" | 거의 없음 | 낮음 (골드·EXP 위주) |
| **성장** | 31~80 | "첫 레어/유니크 드롭" | 50·70층 2회 완만한 벽 | 중간 (어픽스 판별 재미 시작) |
| **중반** | 81~130 | "셋 아이템 조합 시작" | 100층 명확한 벽 | 높음 (마일스톤 보상) |
| **후반** | 131~180 | "레전더리 파밍 전쟁" | 150층 하드 벽 | 매우 높음 |
| **엔드** | 181~200 | "소수의 풀 클리어" | 200층 = 최종 월 | 최고 (200 클리어 특전) |

## 3. 드랍 테이블 설계 방향

### 3.1 기존 자산 재활용 매핑

| 기존 자산 (2019 원본) | Unity 6 재활용 방식 |
|----------------------|---------------------|
| `data_transcendent_stage_reward` (SQL 테이블, `drop_rate` float 보유) | **테이블 구조 그대로 재활용**, 수치만 싱글용 재계산 |
| `RewardItemInfo.xml` (~15,956 드롭 엔트리) | **풀 재활용** — 이미 검증된 드롭 풀 |
| `OptionInfo.xml` 어픽스 풀 | **재활용** — 랜덤 옵션 롤 기반 |
| `EodPlayerDataGenerator.SetItemBasicOption / SetItemRandomOption` (graphify god node 근처) | **로직 참고**, Unity 6에서 DOTS로 재작성 예정 |

### 3.2 층 구간별 등급 확률 (초안)

**원칙**: 디아블로 감성 = "낮은 층에서 전설 드롭 = 이벤트 수준 희귀 / 높은 층에서 전설 = 기대되는 사건"

| 층 구간 | Common | Magic | Rare | Epic | Legendary | Mythic |
|--------|--------|-------|------|------|-----------|--------|
| 1~30   | 70%    | 25%   | 4.9% | 0.1% | 0%        | 0%     |
| 31~80  | 40%    | 40%   | 18%  | 1.9% | 0.1%      | 0%     |
| 81~130 | 10%    | 35%   | 40%  | 13%  | 1.95%     | 0.05%  |
| 131~180| 2%     | 15%   | 45%  | 30%  | 7.5%      | 0.5%   |
| 181~200| 0%     | 5%    | 25%  | 45%  | 22%       | 3%     |

> 이 수치는 **일반 몬스터 드롭 기준**. 보스 드롭은 §3.3 별도 테이블.

### 3.3 보스 드롭 vs 일반 드롭

| 항목 | 일반 몬스터 | 보스 몬스터 (층당 1회) |
|------|-------------|------------------------|
| 드롭 횟수 | 층당 평균 3~6개 | **확정 1개 + 럭키 롤 1~3개** |
| 최소 등급 보정 | 없음 | **Rare 이상 확정** (§3.2 표에서 Common·Magic 자동 재롤) |
| 레전더리 보너스 | §3.2 그대로 | §3.2 확률 × **3배** |
| 셋 아이템 가능 여부 | 불가 | **가능** (100층 이상부터) |
| 마일스톤 키 아이템 | 없음 | 10/50/100/150/200층 보스 **확정 드롭** (§5) |

### 3.4 누적 드롭 모델 vs 개별 드롭 모델 (권장안)

**A안 — 개별 드롭**: 매 층·매 몬스터마다 개별 드롭 계산
- 장점: 디아블로 원조 감성, 온라인 복귀 시 "로그 스크롤의 쾌감"
- 단점: 24시간 방치 = 드롭 로그 수만 개 → UI·DB 폭발

**B안 — 누적 드롭**: 방치 구간은 "n층 평균 × 시간"으로 요약, 복귀 시 결과만 보고
- 장점: 저부하, 모바일에 친화적
- 단점: 재미 반감 — "그 전설 아이템을 몇 층에서 땄는가" 서사 소실

**C안 — 하이브리드 (권장)** ← **PD 승인 요망**
- **능동 세션**: 개별 드롭 + 전체 로그 (디아블로 감성)
- **방치 세션**: 누적 드롭 + **"특이 이벤트" 개별 보존** (Epic 이상만 개별 로그 남김)
- 근거: 24시간 방치에서 Epic 이상 드롭은 평균 10~30개 예상 → UI 부담 낮음
- 복귀 UI: "총 골드 +1.2M, EXP +5K, 특이 드롭 12건 [열기]" 형태

## 4. 아이템 희귀도 체계 (디아블로 감성 6단계)

### 4.1 등급 구조

| # | 등급 (한) | 등급 (영) | 색상 | 어픽스 슬롯 | 기본 드롭률 대역 | 시각 연출 |
|---|-----------|-----------|------|-------------|------------------|-----------|
| 1 | 일반 | Common    | 흰색   | 0           | 40~70%   | 기본, SFX 없음 |
| 2 | 매직 | Magic     | 파랑   | 1~2         | 15~40%   | 기본, 약한 SFX |
| 3 | 희귀 | Rare      | 노랑   | 3~4         | 5~45%    | 광선 이펙트 + SFX |
| 4 | 영웅 | Epic      | 보라   | 5~6 (고정+랜덤) | 0.1~45% | 강한 광선 + BGM 다운턴 + "영웅 드롭!" 팝업 |
| 5 | 전설 | Legendary | 주황   | 고정 5 + 특수 1 (고유 효과) | 0~22% | 화면 흔들림 + 풀스크린 플래시 + 효과음 |
| 6 | 신화 | Mythic    | 녹색(에메랄드) | 고정 6 + 특수 2 (셋 연동) | 0~3% | 레이드급 연출 + 토스트 알림 + 로그 하이라이트 |

> **디아블로 비교**: Common/Magic/Rare/Legendary/Set/Primal = 1:1 대응. 본 설계는 **Set을 Mythic으로 흡수**하여 6단계로 단순화 (1인 제작 부담 축소).

### 4.2 어픽스 슬롯 구조 (OptionInfo.xml 재활용)

```
[장비 아이템]
├── Base Stats (아이템 타입 고정값, 예: 검 공격력 100~150)
├── Prefix (공격 계열 어픽스, OptionInfo 풀에서 롤)
├── Suffix (방어/생존 계열 어픽스)
└── Legendary Affix (Legendary 이상만, 고유 게임플레이 효과)
```

- **Common**: Base만
- **Magic**: Base + Prefix 1 OR Suffix 1
- **Rare**: Base + Prefix 2 + Suffix 2 (최대 4)
- **Epic**: Base + Prefix 3 + Suffix 3 (총 6, 값 범위 +50%)
- **Legendary**: Epic 구성 + **Legendary Affix 1** (예: "치명타 시 주변 적 감전")
- **Mythic**: Legendary 구성 + **Set Affix 1** (세트 2/4/6피스 보너스 연동)

### 4.3 시각적 표현 컨셉

| 요소 | Common/Magic | Rare/Epic | Legendary/Mythic |
|------|--------------|-----------|------------------|
| 드롭 이펙트 | 바닥 점등 | 바닥 + 수직 광선 (1.5m) | 바닥 + 수직 광선(3m) + 화면 플래시 |
| SFX | 짤랑 | 징 + 리버브 | 오케스트라 스팅어 |
| 로그 스타일 | 회색 텍스트 | 색상 텍스트 | **색상 + 박스 하이라이트 + 이모지 prefix** |
| 복귀 팝업 | 묶어서 요약 | 개별 표시 가능 | **개별 팝업 + 스크린샷 공유 버튼** |

## 7. 리스크·미해결

### 7.1 리스크

1. **원본 DPS vs 싱글 방치형 DPS 간극** — 원본 114억 보스 HP가 풀 액티브 전제. 방치형에서는 200층 도달률 <5% 예상. C안(프레스티지) 없으면 엔드게임 공백.
2. **드롭 로그 UI 폭발** — 24시간 방치 시 개별 드롭 보존하면 로그 수백~수천. §3.4 C안 "Epic 이상만 개별" 선택이 필수.
3. **Mythic 드롭률 설정 민감도** — 181~200층 3%는 기대값 기준 하루 2~5개. 너무 많으면 가치 하락, 너무 적으면 동기 소실. 실제 플레이 로그 없이는 튜닝 불가 → Sprint 03 이후 실측 리튜닝 필요.

### 7.2 PD 결정이 필요한 열린 질문 (5개)

1. **Q1. 층 진행 곡선 A/B/C안 중 어느 것?**
   - A: 원본 그대로, 하드코어, 수정 0
   - B: 로그 보정, 방치형 친화, 오버라이드 레이어 1개
   - C(권장): 원본 유지 + 프레스티지 축 신설 (Sprint 02 확장)

2. **Q2. 드롭 모델 A/B/C안 중?**
   - A: 전체 개별 (디아블로 감성 100%, 부하 높음)
   - B: 전체 누적 (저부하, 재미 −30%)
   - C(권장): 하이브리드 — Epic 이상 개별, 그 외 누적

3. **Q3. 등급을 6단계(Common~Mythic)로 확정?**
   - 5단계(Mythic 생략)면 제작 부담 −20%, 엔드 재미 −15%
   - 7단계(+Primal 추가)면 디아블로 재현도 +10%, 제작 +25%

4. **Q4. 소프트 천장 시스템 도입?**
   - 예: 1일 동안 Mythic 2개 이상 드롭 시 추가 드롭률 −50%
   - 도입하면 시즌 길이 ↑, 체감 조작감 ↓ ("왜 안 나오지?" 좌절)
   - 미도입하면 운 좋은 날 5개 나오고 그 다음 날 소진감

5. **Q5. 시즌 리셋 / 프레스티지 도입 시기?**
   - 200층 클리어 = 시즌 종료로 보고 리셋 루프 넣을지
   - 리셋하면 영구 보상(타이틀·파라곤 슬롯) 설계 필수
   - 현 1인 파트타임 기준: **Sprint 05 이후로 유예 권장**

## 부록 A. 수식 검증 샘플 (C안 기준)

가정: 유저 레벨 150, 평균 DPS 1.0M, 150층 보스 HP = 원본 그대로 = 약 5억.
- 이론 클리어 시간 = 5억 / 1M = **500초 = 8.3분**
- 방치 세션 10시간: 150층 클리어 약 72회
- Epic 드롭률 30% × 72 × (보스 3배) = 64.8 → **하루 Epic ~65개**
- Legendary 7.5% × 72 × 3 = 16.2 → **하루 Legendary ~16개**
- Mythic 0.5% × 72 × 3 = 1.08 → **하루 Mythic ~1개**

→ Mythic 1/일은 디아블로 시즌 프라이말 드롭률과 유사 체감. 적정으로 판단되나 실측 필수.
