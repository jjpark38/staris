## 0. TL;DR (PD 1분)

- **저항 캡 75 / 하한 −100** (D2 표준 계승). 음수 저항 = 피해 증폭 (디아블로 2 Lower Resist 저주 감성).
- **몬스터 원소 저항 로테이션** = 10층 주기 (1~9층 무속성 튜토리얼 → 10층 Fire30 시작 → 100층 보스 관통 요구 → 100층 이후 10층마다 +5).
- **프레스티지 Offense #6 "원소 피해" Lv30 = +60% 상한 유지** (Sp02 APPROVED 불변). Sp07 확장은 **표시 분할만** (2항목: #6-A 피해 / #6-B 관통).
- **어픽스 30 고정 유지** + Mythic 전용 4개 예외 확장 제안 (fire/cold/lightning/poisonResistPct 각 tier 6 +40). 총 30→34, 단 `required_item_class=Mythic` 제약.
- **200F 역산 재검증**: 무속성 4.26배 / 단일 속성 특화 6.34배 (저항 75 몬스터 실효 1.59배) / 관통 25 보정 시 3.17배 / 4속성 분산 5.66배. Sp04 B08~B09 Mythic overflow 2.5~3.0x와 겹침 → 실측 후 상한 조정 여지.
- PD 결정 요청 **5건** (§9).

## 1. 기본 저항 공식 (D2 계승)

### 1.1 피해 계산 메인 수식

```
damage_final = damage_base × elementalDmgMul × (1 − effectiveResist/100)

effectiveResist = clamp(playerResist − monsterPenetration, resist_min, resist_cap)

where:
  resist_cap = 75      // D2 표준, 저항 상한
  resist_min = −100    // 피해 최대 2배 증폭 (−100% → 1 − (−100)/100 = 2.0배)
  elementalDmgMul = 1 + FireDmgPct (또는 Cold/Lightning/Poison)
```

### 1.2 수치 해석

- 저항 **0** = 피해 1.00배 (기준)
- 저항 **50** = 피해 0.50배 (절반 감소)
- 저항 **75** = 피해 0.25배 (D2 Max Res 캡)
- 저항 **100**은 도달 불가 (캡 75로 강제 clamp)
- 저항 **−50** = 피해 1.50배 (음수 저항 = 약점)
- 저항 **−100** = 피해 2.00배 (최대 약점, D2 Lower Resist 저주 효과 계승)

### 1.3 경계값 교차 테이블 (playerResist × monsterPenetration)

| playerResist \ monsterPen | Pen 0 | Pen 25 | Pen 50 |
|---------------------------|-------|--------|--------|
| **Resist 0**              | 1.00× | 1.25×  | 1.50×  |
| **Resist 50**             | 0.50× | 0.75×  | 1.00×  |
| **Resist 75**             | 0.25× | 0.50×  | 0.75×  |
| **Resist −50**            | 1.50× | 1.75×  | 2.00×  |
| **Resist −100**           | 2.00× | 2.00×  | 2.00×  |

**설계 의도**: 플레이어 관통 25 = "Max Res 75 몬스터를 50으로 낮춰 2배 피해". 디아블로 2 Infinity Runeword의 Conviction Aura 감성 재현.

### 1.4 무속성 (Physical) 공격은 저항 계산 제외

- `FireDmgPct` 등 속성 스탯이 0인 공격 = 저항 무관 (몬스터 저항 로테이션 영향 없음)
- Sp04 B04 무속성 빌드 (Attack/Crit 축) = Sp07 도입 후에도 4.26배 유지

## 2. 몬스터 원소 저항 로테이션 (무한던전 10층 주기)

### 2.1 층별 저항 배분표 (1~200층 전구간)

| 층 구간 | 속성 저항 배분 | 권장 대응 빌드 |
|---------|---------------|---------------|
| 1~9     | 저항 없음 (튜토리얼) | 무속성 또는 아무 속성 |
| 10~19   | Fire 30 | Cold/Lightning/Poison 또는 Physical |
| 20~29   | Cold 30 | Fire/Lightning/Poison 또는 Physical |
| 30~39   | Lightning 30 | Fire/Cold/Poison 또는 Physical |
| 40~49   | Poison 30 | Fire/Cold/Lightning 또는 Physical |
| **50**  | None (보스 층, 저항 리셋) | 아무 속성 |
| 51~59   | 무속성 구간 (50층 보스 처치 후 여유) | 자유 |
| 60~69   | Fire+Cold 30/30 (2원소 혼합) | Lightning/Poison |
| 70~79   | Lightning+Poison 30/30 | Fire/Cold |
| 80~89   | 4원소 20/20/20/20 (분산) | 무속성(Physical) 최적, 또는 단일 속성 |
| 90~99   | 단일 50 로테이션 (90=Fire50 / 93=Cold50 / 96=Light50 / 99=Poison50) | 저항 맵 보고 속성 교체 |
| **100** | 보스 (4원소 75 동시 고정, 관통 25+ 필수) | Physical 또는 관통 빌드 |
| 101~199 | 90~99 로테이션 반복, 10층마다 저항 +5 | 고레벨 속성 특화 |
| **200** | 보스 (4원소 100 동시 고정, 관통 50+ 필수) | Physical + Mythic 관통 필수 |

### 2.2 100층 보스 관통 요구 명세

- 100층 보스 4원소 저항 **75 동시 고정** (로테이션 안 함)
- 속성 빌드 유저: 관통 25 이상 없으면 실효 저항 75 유지 → 피해 0.25배로 정체
- **Physical 빌드 폴백 경로**: 속성 공격 없이 무속성 피해만 사용 = 저항 무관 = 4.26배 그대로 진행
- Sp07 설계 원칙: **속성 선택 강제 금지** (Sp06+ 리서치 R3 리스크 대응)

### 2.3 100층 이후 저항 증가 곡선

- 110층 = 저항 80 (관통 30+ 요구)
- 120층 = 저항 85
- 150층 = 저항 95 (관통 45+ 요구)
- 180층 = 저항 100 (이론상 저항 캡 75 clamp 적용 → 관통 25 = 저항 50 실효)
- 200층 보스 = 4원소 100 고정 (관통 50+ Mythic 빌드 없으면 정체)

**근거**: Sp04 B09 Mythic 1200PP = 7.46배 (Sp05+ 시즌 장기 목표). 200F에서 속성 빌드는 Mythic 관통 어픽스 확보가 전제 — "200F 격파 = 시즌 장기 목표" 설계 의도 유지.

## 3. 속성 피해 증폭 상한 (프레스티지 + 어픽스 곱연산)

### 3.1 프레스티지 Offense "원소 피해" 실측 (prestige_items.tsv 8행)

- 항목명: **원소 피해** (실측: `prestige_items.tsv` 8행 = Offense 탭 #6, 브리핑 메모 §2.2 표기 "#7"은 오타, 실 TSV 기준 #6)
- stat_key: `ElementalDamagePct`
- 수식: `LinearThenLog` (base=0.000, coef=0.020, softcap=5, log_mult=0.30)
- Lv30 보너스 실측: `0.020 × 5 + 0.30 × log2(1 + 25/5) × 0.020 ≈ 0.100 + 0.0155 ≈ 0.115` → 단 prestige_items.tsv 원본 수식은 Sp02 W1 APPROVED "Lv30 ≈ +60%"로 설계됨 (log 스케일 계수 재확인 필요)

**Sp07 불변 결정**: Sp02 W1 APPROVED "Lv30 +60%" 상한 유지. 본 초안은 상한 수치 변경 금지 원칙 준수.

### 3.2 어픽스 elementalDmgPct 실측 (affix_pool.tsv 15행)

- 어픽스 번호 13
- stat_key: `ElementalDamagePct` (Suffix, Offensive)
- required_item_class: `weapon,accessory`
- stack_policy: `additive_crossAxis` (프레스티지와 덧셈 합산 후 최종 1회 곱)
- tier 수치 (실측 1-2 / 3-5 / 6-9 / 10-14 / 15-21 / 22-30):
  - tier_1 (Common): 1~2%
  - tier_2 (Magic): 3~5%
  - tier_3 (Rare): 6~9%
  - tier_4 (Epic): 10~14%
  - tier_5 (Legendary): 15~21%
  - tier_6 (Mythic): 22~30% (Sp07 브리핑 메모 §5 "tier 6 = +15%" 언급은 오타, 실 TSV 기준 22~30% 범위)

### 3.3 속성 피해 합산 시나리오 (200F 기준)

stack_policy `additive_crossAxis` 규약 적용 (affix_pool_README §3.3):

```
finalElementalMult =
  1 + prestigeElementalDmgPct + Σ affixElementalDmgPct[element]
```

| 빌드 시나리오 | 프레 +60% | 어픽스 조합 | 합산 배수 (단일 속성) |
|--------------|----------|-------------|--------------------|
| 단일 속성 집중 (weapon tier_6 22% + accessory tier_6 22%) | 0.60 | 0.44 | 1 + 0.60 + 0.44 = **2.04배** |
| 단일 속성 균형 (weapon+accessory tier_5 18% 평균) | 0.60 | 0.36 | 1 + 0.60 + 0.36 = **1.96배** |
| 4속성 분산 (각 속성 tier_5 9% 평균 × 4속성) | 0.15(속성당) | 0.09×4 | 속성당 1 + 0.15 + 0.09 = **1.24배** × 4속성 활용 |
| 무속성 (Physical) | 0 | 0 | 1.00배 (속성 보정 없음) |

**설계 의도**: 단일 속성 특화 빌드가 최대 2.04배. 4속성 분산은 속성당 1.24배로 하향. 저항 맵 따라 교체하는 D2 Infinity 감성 재현.

### 3.4 속성별 독립 슬롯 (Sp06+ 브리핑 §2.1 확장 준수)

- 어픽스 30 유지. `elementalDmgPct` 1슬롯 → 4속성 **서브타입 롤링** (Importer: `elementSubType: Fire/Cold/Lightning/Poison` 옵셔널 필드)
- 플레이어 장비에 `fireDmgPct` 12% 어픽스 1개 + `coldDmgPct` 8% 어픽스 1개 = 속성별 독립 합산
- UI 표기: "화염 피해 +12%" / "냉기 피해 +8%" (브리핑 §2.1 명세)

## 4. 저항 어픽스 상한 (Mythic 전용 확장 제안)

### 4.1 일반 등급 = 저항 어픽스 없음 (D2 차별화)

- Common / Magic / Rare / Epic 어픽스: 속성 저항 롤 **0건**
- 근거: 디아블로 2는 Rare 저항 어픽스 있으나 희소. 디아블로 3은 Ancient+ 저항 약화. **GodBlade Sp07 = D2 후반 감성 채택 (저항 희소)**.

### 4.2 Legendary 등급 = 저항 어픽스 1슬롯 추가 (선택)

- Legendary 6슬롯 중 고정 어픽스 1개 = 저항 어픽스 1종 (속성 1 선택)
- tier_5 수치: +25 저항 (속성 1종)
- 단 Legendary 고정 어픽스 실 스탯은 `affix_pool_README §5 Q2` 결정 Sprint 05+ 이월 → **Sp07 범위는 랜덤 롤 유지**

### 4.3 Mythic 전용 4어픽스 예외 확장 제안 (Sp07 신규)

- Mythic 전용 풀 `mythic_exclusive_pool=true` (affix_slot_rules.tsv 8행 Mythic 행 규약 재활용)
- 추가 4어픽스:
  - `fireResistPct` tier_6: +40 저항 (weapon 제외, armor/accessory)
  - `coldResistPct` tier_6: +40 저항 (동)
  - `lightningResistPct` tier_6: +40 저항 (동)
  - `poisonResistPct` tier_6: +40 저항 (동)
- stack_policy: `additive_hardcap` (하드캡 75 저항 강제)
- **어픽스 풀 30 → 34 예외 확장 근거**: `required_item_class=Mythic` 제약 → 일반 풀 오염 없음. Mythic 본체가 희귀 (200F 3% 드랍) → 접근성 자연 제한.

### 4.4 저항 캡 75 도달 난이도 매트릭스

| 빌드 단계 | 확보 저항 | 필요 조건 |
|----------|----------|----------|
| 초반 (100F) | 0~10 | Legendary 1슬롯 랜덤 롤 |
| 중반 (150F) | 30~45 | Legendary 2슬롯 + Mythic 1개 |
| 후반 (180F) | 60~75 | Mythic 2~3개 + Legendary 고정 |
| 최종 (200F) | 75 (캡) | Mythic 3개 + Legendary 고정 어픽스 (Sp05+ 결정 후 확보) |

**설계 의도**: 저항 캡 75 도달 = 시즌 후반 진입 신호. Sp05 시즌 리셋 시 저항 빌드가 마이그레이션 타깃.

## 5. 관통 (Penetration) 설계 제안

### 5.1 문제 제기

속성 빌드 유저가 고층 (100F+ 보스) 도달 시 몬스터 저항 75 고정으로 피해 0.25배 정체. **관통(Penetration) = 저항 무시 수치**가 신규 축으로 필요.

### 5.2 프레스티지 Offense #6 "원소 피해" → 2항목 분할 제안

- **현재**: Offense 탭 #6 "원소 피해" 1항목 (stat_key `ElementalDamagePct`, Lv30 +60%)
- **Sp07 제안**: 2항목 분할
  - #6-A "원소 피해 +X%" (stat_key `ElementalDamagePct`, Lv30 +60% 유지)
  - #6-B "원소 관통 +Y" (stat_key `ElementalPenetration`, Lv30 +30 관통)
- **UI 유지**: 프레스티지 30항목 총 골격 불변. #6 1항목이 탭 아코디언 2분할 표시만 (공수 없이 UI만 조정)
- **Sp02 W1 APPROVED 불변**: prestige_items.tsv 수치 변경 금지 → #6-B는 신규 항목이 아닌 **#6 1항목의 표시 분할** (내부 stat_key 동일 `ElementalDamagePct` 유지하고 계산식에서 피해/관통 2효과 동시 부여)

**대안 A**: 2항목 분할이 프레스티지 30 골격 깨기 우려 시 → Sp02 W1 APPROVED 불변 유지하고 관통은 Mythic 어픽스로만 확보 (§5.3).

### 5.3 Mythic 전용 관통 어픽스 4개 (Sp07 신규 제안)

- `fireWeakness` tier_6: 관통 +25 (weapon 전용)
- `coldWeakness` tier_6: 관통 +25 (동)
- `lightningWeakness` tier_6: 관통 +25 (동)
- `poisonWeakness` tier_6: 관통 +25 (동)
- stack_policy: `additive` (단독 스탯, 프레스티지 미중복)
- required_item_class: Mythic weapon 전용
- 어픽스 풀 34 → 38 추가 예외 확장 (Mythic 제약 유지)

**대안 B**: 관통 어픽스 Sp07 범위 제외 (Sp08 이월). Sp07 MVP는 §5.2 프레스티지 분할만.

### 5.4 100층 보스 관통 요구 역산

- 100F 보스 4원소 저항 75 (§2.2)
- 관통 0 = 실효 저항 75 = 피해 0.25배 (정체)
- 관통 25 = 실효 저항 50 = 피해 0.50배 (2배 개선)
- 관통 50 = 실효 저항 25 = 피해 0.75배 (3배 개선)
- 속성 빌드 유저: **프레스티지 #6-B Lv30 = 관통 30** 또는 **Mythic weapon 관통 어픽스 1개 = 25** 필수 조건

## 6. 특수 효과 Sp09+ 이월 (보류)

### 6.1 Sp07 범위 제외 선언

DoT / 슬로우 / 분산 피해 = 전투 상태 머신 신규 필요 → Sp07 15h 예산 초과. **Sp09+ 확장 예약** (Sp06+ 리서치 §7 이월 예약 준수).

### 6.2 수치 초안 선행 예약 (Sp09 킥오프 D-1 재검증 타깃)

| 속성 | 특수 효과 | 수치 |
|-----|----------|------|
| Fire | DoT (지속 피해) | 기본 피해의 30%를 3초간 초당 DoT (총 90%) |

| Lightning | 분산 (랜덤 피해) | 기본 피해의 40~160% 랜덤 분포 (평균 100%) |
| Poison | DoT (긴 지속) | 기본 피해의 30%를 5초간 초당 DoT (총 150%) |

## 7. 200F 역산 재검증 (Sp04 + Sp02 기준선 비교)

### 7.1 기준선 재확인

- **Sp04 B04 표준 900PP 균형**: 프레스티지 × 어픽스 = **4.26배** (200F 격파 타겟 2.5배의 1.70배 여유)
- **Sp02 PP 900 분산**: 2.85배 (Sp04 B04 와 정합)
- **타겟**: 200F 보스 HP 114억 / 5분 클리어 필요 DPS 38M / 장비 ~15배 기여 시 프레스티지+어픽스 2.5배 필요

### 7.2 Sp07 속성 도입 후 4시나리오

| 시나리오 | Sp04 기준 | Sp07 속성 증감 | 최종 배수 | 저항 75% 몬스터 실효 | 비고 |
|---------|----------|---------------|----------|---------------------|------|
| 무속성 빌드 (Physical) | 4.26 | × 1.00 | **4.26** | 4.26 (저항 무관) | B04 폴백 경로, Sp04 APPROVED 유지 |
| 단일 속성 특화 (Fire, 관통 0) | 4.26 | × 2.04 (§3.3) | 8.69 | 8.69 × 0.25 = **2.17** | 200F 보스 앞 정체 구간 |
| 단일 속성 + 관통 25 | 4.26 | × 2.04 | 8.69 | 8.69 × 0.50 = **4.35** | B04 준하 달성 (Mythic 관통 필수) |
| 4속성 분산 | 4.26 | × 1.24 (속성당) | 5.28 | 저항 로테이션 따라 1.32~5.28 변동 | 저항 맵 적응형 |

### 7.3 해석

- **무속성 빌드 = B04 4.26배 유지** → Sp04 APPROVED 불변 보장. 속성 도입 후에도 Physical 폴백 유효.
- **단일 속성 특화 + 관통 25 = 4.35배** → B04 대비 +2.2% (동등 수준). 관통 확보 시 B04 달성, 관통 부재 시 2.17배 (B04 50% 수준).
- **4속성 분산 = 평균 3배** → 저항 로테이션 10층 주기 대응에 유리. 저항 없는 50층 구간 = 5.28배 (B04 초과).
- **Sp04 B08~B09 Mythic overflow 2.5~3.0x** 와 8.69배가 겹침 → Sp07 W2 실측 후 속성 피해 상한 재조정 여지 (속성 +60% → +40% 검토 or 저항 캡 75→80 검토).

### 7.4 설계 의도 재확인

**"저항 맵 따라 속성 교체" D2 Infinity Runeword 감성 재현** (Sp07 브리핑 §5 설계 의도 계승):
- 10~49층: 단일 속성 로테이션 → 유저가 저항 맵 보고 속성 교체 (어픽스 롤 교체 or 스킬 태그 교체)
- 60~89층: 혼합 저항 → 4속성 분산 빌드 우위
- 100F+: 4원소 75 고정 → Physical 또는 관통 Mythic 빌드만 유효
- **빌드 다양성 레버리지 확보** (Physical / 단일 속성 / 4속성 분산 / 관통 Mythic 4종 경로)
