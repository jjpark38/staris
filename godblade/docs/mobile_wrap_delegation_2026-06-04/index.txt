<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">3. 위임 사유 2건</h2>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">사유 1 — 차도윤 페르소나 약점 (모바일 광고 SDK 0 경험)</h3>
<p class="mb-3 text-text-0"><code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">.claude/agents/web-game-lead.md</code> L26~31 명시:</p>
<blockquote class="my-3 rounded border-l-2 border-gold bg-bg-2 px-4 py-2 text-text-1"><strong class="font-semibold text-text-0">모바일 네이티브 광고 SDK 0 경험</strong> — IronSource / AppLovin 모바일 광고는 류재현(dots-platform) 의존. 웹 광고는 본인 처리 (AdSense / Coinis).</blockquote>
<p class="mb-3 text-text-0">차도윤(차도윤 가정 인용): &quot;현우님, 모바일 wrap 자체보다 광고 SDK 통합이 발목 잡습니다. IronSource Capacitor plugin 자체 PoC 1주 + AppLovin MAX 통합 1주 + 양 OS 정책 검수 1~2주 — 도합 4주 추정인데 저는 0 경험입니다. 류재현님 SDK 본체 + 현우님 wrap 통합 라인이 본인 학습 4주 비용 회피입니다.&quot;</p>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">사유 2 — 정현우 영역 시너지 (Steam Electron + 모바일 wrap = 1 영역)</h3>
<p class="mb-3 text-text-0">정현우 영역에 이미 Steam Electron 빌드 파이프라인이 박혀 있음. 모바일 wrap (Capacitor / Cordova) 도 동일 패턴 — 네이티브 wrap + 빌드 서명 + 스토어 제출. 차도윤이 별도 학습 4주 들이는 것보다 정현우 영역에 합쳐서 1 영역 통합이 학습 비용 0 + 빌드 파이프라인 일관성 확보.</p>
<p class="mb-3 text-text-0">정현우 본인 발화: &quot;Steam Electron 이미 셋업했으니 Capacitor 추가 1~2주면 됩니다. 단 광고 SDK 통합은 류재현님 본체 의존 — 본인은 wrap layer 만.&quot;</p>
