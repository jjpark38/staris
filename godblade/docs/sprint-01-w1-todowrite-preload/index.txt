- **커밋 단위**: 단독 커밋 (가드 #1 확인 직후)

### 3.2 #02 — DropRateTableSO + 60행 Import (2.0h, 최대 태스크)

- **출력**: `DropRateTableSO.cs` + `DropRateTableImporter.cs` + `DropRateTable.asset` + Addressables 엔트리 `Rewards/DropRateTable`
- **DoD**: 60행 로그 `[Import] DropRateTable: 60 rows loaded`
- **경로 상수**: `private const string TSV_REL_PATH = "../designs/transcendent_drop_table.tsv";`
- **가드**: R-DR-01 최초 SO 신설 지점 (CS0579 위험 Medium) + R-DR-02 경로 drift (DialogBox 'TSV Not Found' 발생 시 즉시 STOP)
- **자기검증**: 드롭률 합 = 1.000 ± 0.001 (10 그룹 × 6등급). 실패 시 **TSV 원본 문제** → game-designer 에스컬레이션 (코드 수정 금지)
- **커밋 단위**: 3단 분할 권장 (SO 선 / Importer / Addressables 엔트리)

### 3.3 #03 — MilestoneRewardCatalogSO + 22행 Import (1.5h)

- **출력**: `MilestoneRewardCatalogSO.cs` + `MilestoneRewardImporter.cs` + `.asset` + 주소 `Rewards/MilestoneRewardCatalog`
- **DoD**: 22행 로그 + `_milestoneFloors` HashSet 22 elements

- **가드**: R-DR-01 두 번째 SO — **피로도 Medium → CP-M02 최우선 재체크**. `HashSet<int> _milestoneFloors` 는 `[NonSerialized]` 필드 OK

### 3.4 #04 — AffixPoolSO 뼈대 (1.0h)

- **가드**: R-DR-01 세 번째 SO — **3회 연속 Sp00 회귀 B 동일 패턴 ⚠**. 피로도 축적으로 CS0579 재현 확률 상향
