## 1. 충돌 정의

- 13 (현) + 2 (김민준 요청) = **15** > **14 (박세린 안전권)** = 1 초과
- 16 시 메인 세션 오케스트레이터 검수 부담 +30~40% 추정 (박세린 페르소나 §철학.1 데이터 부재, 추측 헷지)
- D+45 Supabase 백엔드 = 5/18 (Sp-W01 킥오프) + 45일 = **2026-07-02** 채용 시점
- D+90 UGC 모더레이터 = 5/18 + 90일 = **2026-08-16** 채용 시점

## 3. 박세린 권장 default (★ A안)

**A안 채택 권장 사유**:
1. **Tier 14 안전권 사수** — 박세린 페르소나 §철학.1 "일정은 현실" 원칙 + 메인 세션 부담 추정 +30% 회피
2. **UGC 자동 룰 헷지 가능** — spoiler_level v1 (`devlog_v2_spoiler_level_spec.md` 박세린 김민준 협업분) 활용 + 욕설 필터 D+150 사전 도입
3. **류재현 페르소나 침범 회피** — C안 위험 (DOTS specialist → UGC 모더 영역 침범) 큼
4. **1인 PD 30일 부담 헷지 가능** — D+150 자동 룰 + 박세린(PM) 일일 알림 1쪽

**위험 가정 2건**:
- A1: UGC 자동 룰 효율 가정 (실측 0). 욕설 필터 + spoiler_level high = 박세린 + 강시연 + PD 3자 검수 라인 재활용 가정.
- A2: PD 30일 1인 부담 = 5h/주 가정 (10~15h/주 가용 중). 본업 가중 시 D+170 긴급 채용 가능성.
