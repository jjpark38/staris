<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">3. 소프트캡 공식 (Calculator 수식화 가능)</h2>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">3.1 수식</h3>
<pre class="my-4 overflow-x-auto rounded border border-border bg-bg-1 p-4 text-[13px]"><code>CalculateLevel(int investedPp, byte softCap=5):
    누적 비용 테이블(prestige_pp_cost.tsv)로 역조회 — cumulative_pp 가 investedPp 이하인 최대 level 반환
    Lv 상한 = 100 (pp_cost.tsv 최종 행)

CalculateBonus(row, level):
    if row.effect_type == PercentStat or Multiplier:
        if level &lt;= softCap:
            bonus = row.per_level_value * level                           // 선형
        else:
            preCap  = row.per_level_value * softCap                       // Lv5까지 쌓인 기본
            postLv  = level - softCap
            bonus   = preCap + row.per_level_value * row.post_softcap_diminish * log2(1 + postLv)
        return row.base_value + bonus
    elif row.effect_type == FlatStat:
        if row.curve_id == FlatCapped:
            return row.base_value + row.per_level_value * min(level, softCap)  // Lv5 이후 증가 없음
        elif row.curve_id == FlatSteps:
            return row.base_value + row.per_level_value * min(level, softCap)  // IdleCapHours 동일</code></pre>

<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">6. Sprint 02 W2 code-lead 임포터 자기검증 체크포인트 (5개)</h2>
<p class="mb-3 text-text-0">code-lead 의 <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">PrestigeItemImporter</code> 가 TSV 로드 직후 반드시 검증해야 할 항목:</p>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1"><strong class="font-semibold text-text-0">[CP-T1] 행 수 강제 = 30</strong></li></ol>
<ul class="mb-3 ml-5 list-disc text-text-0"><li class="mb-1"><code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">rows.Count != 30</code> → <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">InvalidOperationException(&quot;PrestigeItemImporter: expected 30 rows, got {n}&quot;)</code> + Importer 중단 + <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">DisplayDialog</code>.</li><li class="mb-1">Sprint 02 범위는 30항목 고정. 29/31 시 튜닝 실수 감지.</li></ul>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1"><strong class="font-semibold text-text-0">[CP-T2] <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">tab</code> 리터럴 화이트리스트</strong></li></ol>
<ul class="mb-3 ml-5 list-disc text-text-0"><li class="mb-1">허용값: <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">Offense</code> / <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">Defense</code> / <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">Utility</code> (정확한 PascalCase).</li><li class="mb-1"><code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">Unknown</code> / 소문자 / 공백 포함 시 <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">ArgumentException</code>.</li><li class="mb-1">탭별 카운트 검증: Offense=10 / Defense=10 / Utility=10. 불일치 시 중단.</li></ul>

<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">7.1 최우선 튜닝 대상 (Sprint 03 플레이테스트 직후)</h3>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1"><strong class="font-semibold text-text-0">item_id=0 공격력 per_level 2.0%</strong>: 다른 곱연산 축(치피·보스)과 곱해지면 체감 폭이 너무 클 수 있음. 1.5%로 하향 가능성.</li><li class="mb-1"><strong class="font-semibold text-text-0">item_id=24 방치 수익 증폭 per_level 3.0%</strong>: 복리 루프 (방치로 PP 적립 → PP 찍어 방치 수익 증폭 → 더 많은 방치 PP). 폭주 감지 시 1.5%로 하향 + 하드캡 추가.</li><li class="mb-1"><strong class="font-semibold text-text-0">item_id=26 PP 획득량 per_level 1.5%</strong>: 메타 가속 축. 모든 원천에 곱해지면 소프트캡 이후에도 복리 효과 우려. diminishing 0.25 → 0.15 로 강화 가능.</li></ol>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">7.2 후순위 튜닝 대상 (Sprint 04+ 장비 도입 후)</h3>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1"><strong class="font-semibold text-text-0">장비 기여 15배 가정 재검증</strong>: Sprint 03 Mythic 장비 스펙 확정 후 200층 역산 재계산. 장비 기여가 10배로 축소되면 프레스티지 필요 기여 ↑ → per_level 계수 일괄 상향.</li><li class="mb-1"><strong class="font-semibold text-text-0">item_id=9 장비 옵션 증폭 0.8%</strong>: 장비 어픽스 풀 크기·기대값이 확정돼야 의미 결정. 현 0.8%는 잠정.</li><li class="mb-1"><strong class="font-semibold text-text-0">item_id=25 방치 캡 시간 최대 +10h</strong>: 34h 캡이 유저 패턴에 맞는지. 광고 48h 확장과의 중복 허용 여부 (현재 별도 누적 가정).</li></ol>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">7.3 Sprint 05 시즌 도입 전 재논의 (Q3 관련)</h3>
