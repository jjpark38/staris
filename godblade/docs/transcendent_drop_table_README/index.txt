## 4. 등급 리매핑 규칙 (원본 4 → 신규 6)

| 원본 Grade | 출현수(RewardItemInfo) | 신규 매핑 | 비고 |
|------------|------------------------|-----------|------|
| Normal     | 2,535 | **Common** | 기본 템 그대로 |
| (없음)     | — | **Magic** | 신규 — 어픽스 2슬롯 저가 접근 |
| Superior   | 3,386 | **Rare** | Superior를 Rare로 승격 (Diablo 식) |
| Rare (원본)| 3,743 | **Epic** | 원본 Rare는 실질 상위 템 → Epic으로 흡수 |
| Unique     | 2,960 | **Legendary** | 1:1 |
| (없음)     | — | **Mythic** | 신규 — 시즌 최상위 |

**근거**: 원본 EOD는 4등급이지만 신규 방치형 6등급 체계를 위해 `Magic` / `Mythic` 두 층을 신설. Importer 는 기존 XML의 `Grade` 컬럼을 위 매핑표로 치환하여 `drop_table.tsv` 의 grade 와 충돌 없이 통합.

> **I-3 패치 (2026-05-04, #W1-03)**: `transcendent_affix_pool.tsv` 의 `legacy_grade_map` 컬럼은 원본 자산 추적용 메타데이터로, **Sp01 W2 Importer는 본 컬럼을 무시**한다 (등급 리매핑은 §4 표만 진실). R2 정책(Magic 베이스 = Normal 복제)은 Sp02 W2 코드 분기로 처리.

## 5. 드롭률 합 검증

| 층 구간 | 일반 합 | 보스 합 |
|---------|---------|---------|
| 1~30     | 1.000 | 1.000 |
| 31~80    | 1.000 | 1.000 |
| 81~130   | 1.000 | 1.000 |
| 131~180  | 1.000 | 1.000 |
| 181~200  | 1.000 | 1.000 |

모든 구간 합 = 1.000 ± 0.000. 오차 없음.

### 5.1 Mythic 기대치 검증 (181~200층 일반)

- 드롭률 3% = 0.030 / 마리
- 평균 방치 10h · 분당 약 36 마리 (Sprint 00 DPS 초안 기준) → 21,600 마리
- 181~200층 체류 비중 10% 가정 → 2,160 마리
- Mythic 기대 = 2,160 × 0.030 = **64.8개** (10h 기준, 181~200 구간만)

초안보다 기대치가 크므로, **`Epic 이상만 개별 보존` 필터(Q2)** 가 반드시 켜져야 로그 폭주 방지. `settings.idle.keepIndividualLogFromGrade = "Epic"` 상수로 code-lead에 전달.

## 6. Sprint 01 W2 code-lead 임포터 검증 체크포인트

1. **Grade 리매핑 변환 테이블** — §4 의 4→6 매핑을 `GradeRemap.cs` enum 또는 Dictionary 로 하드코딩. 누락 시 Importer 에서 즉시 Fail (Unknown grade exception).
2. **드롭 테이블 검색 함수는 `(floor:int, mobKind:enum, grade:enum)` 키** — 60행 테이블을 런타임 Lookup O(1) 로. Dictionary<(int,int,int), float> 추천.
3. **층 구간 경계값 편입 규칙** — `floor_range_min <= floor <= floor_range_max` (양끝 포함). 30/31 경계에 테스트 케이스 2개 필수.
4. **TSV 파서 "TBD_" 프리픽스 처리** — `reward_code`가 `TBD_` 로 시작하면 플레이스홀더 로그만 남기고 Skip (임시, Sprint 02 이후 실제 코드로 치환 예정).
5. **드롭률 합 자기검증** — Importer 끝에서 층 구간별 합이 1.000 ± 0.001 인지 Assert. 벗어나면 Editor 콘솔에 Error 로그 (런타임 Crash 금지).
6. **어픽스 풀은 Week 2 완결 금지** — `affix_pool.tsv` 6행은 "뼈대". 실제 `OptionItemRandom` 211행 접합은 Sprint 02 로 이월 권장. Week 2 엔 "Grade→슬롯 수"만 반영해도 충분.
7. **마일스톤은 드롭 테이블과 별도 경로** — 10/50/100/150/200 층에서 `MilestoneGranter.Award(floor)` 같은 이벤트 한 번만 실행, 드롭 Roll 과 중복 지급 금지.

## 7. 리스크 · 미해결

- **R1**: 원본 `EquipType` 리터럴 전체 목록 미확인 (`Ring/Weapon/Armor` 세 가지만 샘플 확인). 드롭테이블에 슬롯 필터 추가 필요 시 code-lead 가 Importer 단계에서 값 수집 후 PD에게 컬럼 추가 제안.
- **R2**: `Magic` 등급 신규 도입에 따른 원본 자산(베이스 아이템) 부족 — Sprint 02에서 `ItemInfo.xml` 의 `Normal` 베이스를 복제해 `Magic` 파생을 만드는 방안을 code-lead·game-designer 공동 결정.
- **R3**: Mythic 기대치 64.8개/10h 는 원본 몬스터 스폰율이 유지된다는 전제. `TranscendentStageSO.bossSpawnHpAmount`가 200층에서 114억 HP이므로 실제 DPS 확정 전까지는 추정치 (±50% 편차 각오).
- **R4**: 시즌 리셋 (Q5) 이 Sprint 05 이후로 유예됐으므로, Mythic 누적 상한/디센팅 정책 미정. 초기 출시 구간에 Mythic 인플레 우려 → Sprint 03 회고에서 재검토.
