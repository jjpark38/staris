**W1 T1 합/불합 판정**:

### 1.3 ITimeProvider 주입 패턴 (Sp03 IdleTicker 시계 가드 패턴 재활용)

```csharp
namespace GodBlade.Runtime.Common {
  public interface ITimeProvider {
    System.DateTime UtcNow { get; }
    long UtcNowUnixMs { get; }
  }
  public sealed class SystemTimeProvider : ITimeProvider {
    public System.DateTime UtcNow => System.DateTime.UtcNow;
    public long UtcNowUnixMs => System.DateTimeOffset.UtcNow.ToUnixTimeMilliseconds();
  }
}
```

**왜 신설하는가**: dry-run §5.1 결정론 주의 — `IsSeasonEnded()`는 `DateTime.UtcNow` 직접 비교 금지 → `ITimeProvider` 주입으로 테스트 가능화. **Sp03 IdleTicker 가 이미 동일 패턴 사용 중일 가능성** = D-1 (2026-06-28) code-lead B1 실측으로 확인. 미적용 시 신설 +0.5h.

**T1 의존**: ITimeProvider 가 Sp03 에 이미 존재하면 재활용 (0h) / 미존재 시 신설 (+0.5h)
