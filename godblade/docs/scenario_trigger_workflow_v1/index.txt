4:T18ae,# PD 본문 9권 → 게임 시나리오 트리거 변환 워크플로우 v1

> 작성: 윤서아 (game-designer, 2026-05-04 채용 D+0 첫 발주)
> 본 문서 위치: `designs/scenario_trigger_workflow_v1.md`
> 전제: 박세린 인수인계 9h 학습 가정 + v3.0 13건 결정 + 200F 4.255 baseline + 35어픽스 + 30프레스티지 + 60일 시즌 + 강시연 산하 라인 100% 인수
> 영역: 윤서아(추출/보강/검증) + 강시연(윤문) + 차도윤(임베드) + 한가영(baseline 영향 0 검증)
> APPROVED-BY: PD default 채택 천명 (2026-05-04)

---

## TL;DR (3줄)

1. **100 트리거 슬롯** = 1F~50F × (진입전 + 진입후) 2슬롯/F. 시나리오 모드 단독 영역.
2. **9권 ↔ 1F~50F 매핑** = 1~5권만 시나리오 모드 (5권당 12화 평균 × 50F = 1.20화/F). 6~9권은 무한 모드 200F~1000F+ 보스 트리거로 분리.
3. **200F 4.255 baseline 영향 0** — rex-dialogue UI 팝업 + 본문 발췌 텍스트만. 전투/드롭/어픽스/프레스티지/시즌 영향 0 가정.

---

## 1. 변환 워크플로우 5단계

| # | 단계 | 입력 | 출력 | 담당 |
|---|------|------|------|------|
| 1 | **본문 청킹** | PD 본문 (1권~9권 .md) → 강시연 윤문 결과 | 장면별 청크 (캐릭터 등장 / 대사 / 액션 / 배경 4 라벨) | 강시연 (구조 재배열 가능) |
| 2 | **트리거 슬롯 추출** | 청크 + 1F~50F 100 슬롯 매트릭스 | 슬롯별 ID `S-F<NN>-<pre|post>` (예: `S-F03-pre`) | 윤서아 |
| 3 | **본문 발췌** | 청크 → 50~150자 발췌 (rex-dialogue 포맷 호환) | 발췌 텍스트 + 발화자 + 톤 라벨 | 윤서아 (강시연 톤 동의) |
| 4 | **게임 보강** | 발췌 사이 빈 슬롯 + GDD v5 + 어픽스 35 + 시즌 60일 | 보스 등장 알림 / 어픽스 해금 / 시즌 이벤트 / 튜토리얼 힌트 | 윤서아 (게임 전용) |
| 5 | **검증** | 100 트리거 풀 + baseline 시트 4종 | 트리거 정합 + baseline 0 영향 + 강시연 톤 동의 + 한가영 시뮬 | 윤서아 + 강시연 + 한가영 |

**산출 포맷** (각 트리거 1행):
```
S-F<NN>-<pre|post> | <source: 본문|보강> | <발화자> | <톤> | <50~150자> | <연출 힌트>
```

| PD 본문 진행률 | 시나리오 모드 자동 다운그레이드 |
|--------------|-----------------------------|
| 5권 미달 (4권까지) | **40F 다운그레이드** (10F 무한 모드 흡수) |
| 3권 미달 | **25F 다운그레이드** (메모리 v3.0 #1 헷지 정합) |
| 1권 18화만 | **5F 튜토리얼 수준** + 박세린(PM) 일정 보고 의무 |

### 200F 4.255 baseline 영향 평가

- 시나리오 모드 = **rex-dialogue UI 팝업 + 본문 발췌 텍스트만**
- 전투 / 드롭 / 어픽스 / 프레스티지 / 시즌 / IdleCap / 광고 / PP 자동 영향 **0**
- 한가영 주 1회 자동 회귀 검증 결과에 트리거 추가 시 영향 평가 컬럼 1건 추가 (윤서아 별도 발주)
- **200F 4.255 baseline 절대 보존** (Sp01 W1 결과 정합)
