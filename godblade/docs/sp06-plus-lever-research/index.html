  • 디아블로 감성·싱글 전제·1인 예산 3대 원칙 적용 결과:
    • 필수 (Sp06~07 권장): 속성 스킬 시스템 (디아블로 Resistance·Elemental Damage 감성 + 어픽스와 직결)

  • Sp06+ 로드맵 제안 (§5): Sp06=기존 이월 5건 소화 / Sp07=속성 스킬 시스템 / Sp08=주간 이벤트 리더보드 / Sp09=재검토 분기 / Sp10+=Follower 검토.

1. 4대 원칙 재확인 (레버 판정 기준)

본 리서치의 레버 판정은 다음 4축 기준으로만 판단한다:

축기준비중
A. 디아블로 감성 적합어픽스 빌드 / Legendary·Mythic 희귀성 / 원소 저항·피해 / 파밍 루프와 충돌 없는가높음
B. 싱글 플레이어 전제Firebase Firestore 리더보드 이상의 서버 인프라를 요구하는가 / 비동기 PvP 가능한가매우 높음
C. 1인 파트타임 예산2주 스프린트 1~2개 내 MVP 가능한가 / 신규 툴·에디터 필요한가매우 높음
D. 시장 차별화방치형 RPG 시장에서 GodBlade 고유 판매 포인트로 기능하는가중간

Sp01~05 기구축 인프라 재활용이 가능하면 C축 가산점. 기반 아예 없으면 C축 감점.

2. 4종 레버 × 4축 스코어 매트릭스

2.1 레버 #1 — 경쟁 콘텐츠 (PvP / 레이드 / 확장 리더보드)

벤치마크: 버섯커 "텃밭 훔치기"·"용병 빼앗기" / 사신키우기 "협동 레이드" / AFK Arena "Arena of Heroes".

축점수판정
A 디아블로 감성★★★☆☆D2 Baal Run·D3 Greater Rift Leaderboard는 경쟁 DNA. 단 텃밭 훔치기·용병 빼앗기는 모바일 소셜 감성이라 톤이 다름
B 싱글 전제★★☆☆☆비동기 PvP는 서버 저장소+전투 시뮬 공유 필요. Firestore만으론 부족 → 서버리스 원칙 깨짐
C 1인 예산★☆☆☆☆PvP/레이드 풀 구현은 4~6주. 협동 실시간은 Photon/Relay 도입 필요 — 서버리스 방향과 충돌
D 시장 차별화★★★☆☆없어도 리더보드로 대체 가능. 단 주간 이벤트 랭킹은 신선도 레버리지 강

변형안: "주간 리더보드 이벤트" — 이미 Sp05 Firestore 리더보드 있음. 추가로 주간 제한 던전(예: "Legendary 2개 이상 착용 금지 모드", "공속 +50% 부스트 층 러쉬") 1~2종을 Firestore 컬렉션으로 붙이면 PvP 없이도 경쟁감 구현 가능. 풀 비용 2주 스프린트 1개.

**비동기 유사 PvP (Follower 전투 공유)**도 검토 가능하나 Sp10+ 이월 타당. 유사작: Dungeon Raid 계열.

옵션비용추천
(a) 실시간 PvP 도입6~8주 + Photon배제 — 서버리스 원칙 위배
(b) 비동기 PvP (Follower 공유)3~4주 + Cloud FunctionSp10+ 이월
(c) 주간 제한 리더보드 이벤트2주Sp08 권장
(d) 협동 레이드6주 + 실시간 인프라배제

2.2 레버 #2 — 속성 스킬 (4속성 / Elemental Damage)

벤치마크: 달토끼 키우기 4속성(달/불/물/빛/어둠) / AFK Arena 5원소(Light/Dark/Wild/Graveborn/Celestial) 상성.

축점수판정
A 디아블로 감성★★★★★D2 Resistance / D3 Elemental Damage % / D4 Resistances Rework — 원소는 디아블로 DNA 그 자체
B 싱글 전제★★★★★순수 클라 전투 확장. 서버 영향 0
C 1인 예산★★★★☆어픽스 elementalDmgPct·프레스티지 원소 피해 항목이 이미 슬롯으로 선반영됨 (affix_pool §2.2 / prestige_system §4.3 Offense 탭 #7) → 풀 신설 아닌 활성화
D 시장 차별화★★★☆☆원소 시스템은 시장 표준화. 단 디아블로식 "저항 70% 벽" 감성을 방치형에 이식하면 어필

이미 GodBlade에 선반영된 훅:

  • affix_pool.tsv elementalDmgPct 어픽스 (Offensive 13개 중 1개)
  • prestige_items.tsv Offense 탭 #7 "원소 피해"
  • transcendent_drop_table_README.md: Mythic 등급 이상 보스에서 원소 저항 옵션 슬롯 잠재 확장 공간

Sp07 범위 권장:

  • 속성 4종 확정 (Fire / Cold / Lightning / Poison — D2 고전 4원소 계승 / 빛·어둠은 Sprint 09+ Holy/Shadow 확장 여지)
  • 몬스터별 원소 저항 1종 부여 (무한던전 10층 단위 로테이션)
  • 어픽스 elementalDmgPct를 속성별 4슬롯으로 세분화 (기존 1슬롯 → 4슬롯. 어픽스 30개 유지, 내부 분기만)
  • 스킬 4개에 속성 태그 부여 (신규 스킬 추가 아님 — 기존 스킬에 태그만)
옵션비용추천
(a) 4속성 + 저항 + 어픽스 분기2주Sp07 권장
(b) 6속성 (달토끼식 + 빛/어둠)3주Sp09+ 확장 여지

2.3 레버 #3 — 동료 / 미소녀 수집

벤치마크: 우산소녀 키우기 (우산 정령 수집) / AFK Arena (영웅 수집) / 세븐나이츠 키우기.

축점수판정
A 디아블로 감성★☆☆☆☆미소녀 수집은 디아블로 DNA와 충돌. D3 Follower(Templar/Scoundrel/Enchantress)가 최근접 — 변형 도입 시만 가능
B 싱글 전제★★★★★순수 클라 시스템
C 1인 예산★☆☆☆☆동료 10명 기준 아트·보이스·개별 스킬 = 풀 수집형 게임 1개 분량. 1인 파트타임에 파산적
D 시장 차별화★★★★☆수집형은 레드오션. GodBlade가 따라가면 우산소녀/세나키의 열위 카피가 됨

변형안: D3 Follower 구조 — 1~2명 NPC 동료 (이름: "수호자 파편에서 소환된 영령" 네러티브). 디아블로 Templar/Scoundrel/Enchantress 식으로:

  • 각 1종 슬롯 (Tank / DPS / Support) 최대 1명 동시 운용
  • 개별 장비 5슬롯 (무기·방어 단순화)
  • 어픽스 풀 공유 (제작 비용 최소화)
  • 아트는 실루엣 + 이름 + 1~2줄 설명만 (미소녀 수집 회피)

이조차 Sp10+ 이월이 타당. 기본 시스템(어픽스·프레스티지·시즌) 안정화가 선행.

옵션비용추천
(a) 풀 동료 수집 (10명+)8주+ 아트·보이스배제 — 디아블로 감성·1인 예산 양쪽 파탄
(b) 변형 Follower (1~2슬롯 NPC)3~4주Sp10+ 이월 검토
(c) 현 수호자(Guardian) 시스템 확장2주Sp09+ 중간안
(d) 배제-Sp01~05 범위 내 결정

참고: 현 GodBlade에 이미 "수호자(Guardian)" 개념이 TranscendentStageSO.guardianExp 필드로 존재. 이를 "전투 참여 펫/소환수"로 승격하면 (c) 중간안 가능. 단 이는 원본 자산 재해석이지 신규 레버는 아님 → 별도 리서치 건으로 분리 (Sp09 W1 권장).

2.4 레버 #4 — 전직 시스템 (버섯커 30레벨 전직)

벤치마크: 버섯커 키우기 30레벨 전직 / 세나키 영웅 등급업 / Path of Exile Ascendancy Class.

축점수판정
A 디아블로 감성★★★☆☆D3 Set Dungeon 특화·D4 Class Mechanic(Druid Spirit Boons) 비슷. 단 "전직 = 캐릭터 변환"은 D 시리즈에 없음 (클래스 고정)
B 싱글 전제★★★★★클라 전용
C 1인 예산★★☆☆☆전직 35개 × 신규 스킬트리 = Sprint 34개. 기존 프레스티지 30항목과 중복 축
D 시장 차별화★★☆☆☆국내 방치형 표준. 없어도 불이익 없음

핵심 통찰: GodBlade의 프레스티지 3탭×10항목 = 사실상 전직 시스템의 D3 Paragon 감성 변형. "Offense 올인 = 버서커 / Defense 올인 = 팔라딘 / Utility 올인 = 시프" 빌드가 이미 30항목 배분으로 가능. 별도 전직 레이어를 덧씌우면 프레스티지와 축이 중복 → 유저 인지부하 증가.

옵션비용추천
(a) 전직 3종 + 신규 스킬트리6~8주배제
(b) 프레스티지 "특화 프리셋" 추가1주Sp08 W2 마이크로 기능으로 흡수 권장 (프리셋 버튼 UI만)
(c) 시즌별 일시 전직 (보너스 효과)3주Sp11+ 시즌 테마화 여지
(d) 장기 이월-필요 시 Sp12+ 재검토

권장: (b) — 프레스티지 자동배분 프리셋 3종 ("공격 특화 / 생존 특화 / 경제 특화")을 prestige_system_spec.md §7.1에 이미 언급했으므로 Sp08 W2에서 실제 UI 버튼만 붙이면 된다. 전직 감성의 70% 대체.
