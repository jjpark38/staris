<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">4.2 채널 경계 불변식</h3>
<pre class="my-4 overflow-x-auto rounded border border-border bg-bg-1 p-4 text-[13px]"><code>불변식 I1: IsUnlocked == false 이면 Slots.Count == 0
불변식 I2: Σ(slot.investedPp where channel=Permanent) ≤ PermanentPp
불변식 I3: Σ(slot.investedPp where channel=Seasonal)  ≤ SeasonalPp
불변식 I4: Sprint 02~04 기간 SeasonalPp == 0 이고 Seasonal 채널 슬롯 없음
불변식 I5: MigrateSeasonalToPermanent 후 SeasonalPp == 0, Seasonal 슬롯 모두 Refund → Permanent Pp 풀로 편입 (비율 적용)</code></pre>
<ul class="mb-3 ml-5 list-disc text-text-0"><li class="mb-1">테스트(§7)에서 I1~I5 모두 검증.</li></ul>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">4.3 마이그레이션 알고리즘 (의사코드)</h3>
<pre class="my-4 overflow-x-auto rounded border border-border bg-bg-1 p-4 text-[13px]"><code>MigrateSeasonalToPermanent(retainRatio=0.5):
  // Step 1: Seasonal 슬롯 전부 회수 (invested pp 모음)
  seasonalInvested = Σ slot.investedPp where channel=Seasonal
  totalPool = SeasonalPp + seasonalInvested   // 미투자 + 투자 모두
  RemoveAll(s =&gt; s.channel == Seasonal)

  // Step 2: retainRatio 적용하여 Permanent Pp 풀에 적립
  converted = floor(totalPool * retainRatio)
  PermanentPp += converted
  SeasonalPp = 0

  // Step 3: 이벤트 발화 (UI 갱신)
  OnPpChanged(Permanent, PermanentPp)
  OnPpChanged(Seasonal, 0)</code></pre>
<ul class="mb-3 ml-5 list-disc text-text-0"><li class="mb-1"><code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">retainRatio</code> 인자화 → Sprint 05 시점에 PD가 비율 조정 가능 (기본 0.5 = 스펙 Q3).</li><li class="mb-1">부동소수 누적 오차 방지: <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">long <em class="italic"> float</code> 대신 <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">long </em> numerator / denominator</code> 정수 연산 고려(Sprint 05 재검토).</li></ul>
