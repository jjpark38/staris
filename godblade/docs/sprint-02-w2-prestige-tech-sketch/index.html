1. 데이터 모델 선택

1.1 전제: 슬롯 수 × 상태 성격

  • 슬롯 수: 30항목 × 2채널 = 유저 1인당 60 슬롯.
  • 성격: 투자·회수·리스펙 빈도 높음. Read-mostly가 아니라 read-write hot path.
  • Sprint 01 W2 DropRateTableSO / MilestoneRewardCatalogSO 는 read-only 카탈로그 → SO 적합. 프레스티지 상태는 유저 세이브 → SO 적합도 낮음.

// GodBlade.Runtime — Assets/_Project/Scripts/Runtime/Prestige/PrestigeSlot.cs
namespace GodBlade.Runtime.Prestige {
  public enum PpChannel : byte {
    Permanent = 0,
    Seasonal  = 1,
  }

  [System.Serializable]
  public struct PrestigeSlot : System.IEquatable<PrestigeSlot> {
    public ushort itemId;       // PrestigeItemCatalogSO 의 row index (0~29)
    public PpChannel channel;   // 1 byte
    public int investedPp;      // 누적 투자 PP (회수 시 감소)
    // Level·Bonus 는 저장하지 않음 — PrestigeCalculator 가 실시간 산출 (카탈로그 공식 변경 시 재컴파일 대응)
  }
}
  • PrestigeSlot 은 blittable (byte + ushort + int) → Sprint 03 DOTS 전환 시 IComponentData 로 1:1 이식 가능.
  • 저장 엔티티는 아래(§3)의 PlayerPrestigeState 한 클래스가 소유.

4. PP 슬롯 2채널 구조 (Q3 핵심)

4.1 설계 목표

  • Sprint 02~04 기간: Seasonal 채널은 UI에서 잠금 표시(탭 노출 자체 금지 또는 회색 처리). AddSeasonalPp 는 호출 가능하지만 트리거 경로 없음 → 실질적으로 0 유지.
  • Sprint 05 시점: SeasonSystem 신설 → OnSeasonEnd 이벤트가 MigrateSeasonalToPermanent(0.5f) 호출. 본 W2에서는 메서드 시그니처만 존재, 호출자 없음.

4.2 채널 경계 불변식

불변식 I1: IsUnlocked == false 이면 Slots.Count == 0
불변식 I2: Σ(slot.investedPp where channel=Permanent) ≤ PermanentPp
불변식 I3: Σ(slot.investedPp where channel=Seasonal)  ≤ SeasonalPp
불변식 I4: Sprint 02~04 기간 SeasonalPp == 0 이고 Seasonal 채널 슬롯 없음
불변식 I5: MigrateSeasonalToPermanent 후 SeasonalPp == 0, Seasonal 슬롯 모두 Refund → Permanent Pp 풀로 편입 (비율 적용)
  • 테스트(§7)에서 I1~I5 모두 검증.

4.3 마이그레이션 알고리즘 (의사코드)

MigrateSeasonalToPermanent(retainRatio=0.5):
  // Step 1: Seasonal 슬롯 전부 회수 (invested pp 모음)
  seasonalInvested = Σ slot.investedPp where channel=Seasonal
  totalPool = SeasonalPp + seasonalInvested   // 미투자 + 투자 모두
  RemoveAll(s => s.channel == Seasonal)

  // Step 2: retainRatio 적용하여 Permanent Pp 풀에 적립
  converted = floor(totalPool * retainRatio)
  PermanentPp += converted
  SeasonalPp = 0

  // Step 3: 이벤트 발화 (UI 갱신)
  OnPpChanged(Permanent, PermanentPp)
  OnPpChanged(Seasonal, 0)
  • retainRatio 인자화 → Sprint 05 시점에 PD가 비율 조정 가능 (기본 0.5 = 스펙 Q3).
  • 부동소수 누적 오차 방지: long float 대신 long numerator / denominator 정수 연산 고려(Sprint 05 재검토).
