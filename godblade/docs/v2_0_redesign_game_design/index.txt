- v1.2 6단계 로드맵 (Unity 24~30M 단일 출시) → **v2.0 = "웹게임 D+90 선출 + Unity 후속"** 격변. 강시연 1권 18화 = 시나리오 모드 1F~50F 트리거 본맥, `data_transcendent_stage` 200F 4.21배 (메모리 `project_sprint01_w1_results.md`) = 무한 모드 baseline 보존.

### 18F~50F (2권 본문 33화)

`project_volume2_synopsis_v2_decisions.md` v2.4 매핑 그대로 사용. 무당파 9화 / 개방 6화 / 소림사 7화 / 곤륜파 19화 (29~48화). 50F = 곤륜산 정상 종료 = 2권 클라.

**트리거 총량**: 1F~50F × 2점 (전/후) = **100 트리거**. 단 4~10F 패밀리 결성 7화 = 7×2 = 14 + 보스전 컷신 5건 추가 = **약 120 트리거**. 강시연 본문 인용 + 게임 전용 보강 (시즌 시험 라벨 / 어픽스 트리거 / 다음 층 힌트) 50/50.

**51F~ 무한 모드 진입**: 시나리오 OFF / 1000F+ 영원 사냥. 50F 종료 시 PD 본문 2권 50화 클라 컷신 + "무한 모드 해금" 토스트.

## 3. 무한 모드 밸런스 곡선 (51F → 1000F → ∞)

### baseline (메모리 잠금)

- **200F = 4.255배** (`project_sprint01_w1_results.md` W1-04 PASS 0.12% 편차) = 절대 baseline. v2.0에서 변경 0건.
- **공식**: `DPS_F = baseline × prestige(2.30x) × affix_epic_6슬롯(1.85x)` = 200F에서 4.255 검증 완료.

### v2.0 신규 곡선 (51F~1000F)

| 구간 | DPS 배율 (vs 1F baseline) | 드롭 등급 비율 | 설계 근거 |
|------|------------------------|---------------|---------|
| 51F~100F | 1.0 → 2.0 (선형) | Common 80% / Magic 18% / Rare 2% | 1권 시나리오 종료 직후, 진입 장벽 낮게 |
| 100F~200F | 2.0 → 4.255 | Common 60% / Magic 30% / Rare 9% / Epic 1% | 200F = 메모리 baseline 정합 |
| 200F~500F | 4.255 → 12.0 (지수 ×1.005/F) | Magic 50% / Rare 35% / Epic 13% / Mythic 2% | Epic 슬롯 풀 활성화 / Mythic 폭주 (Sp04 v1.1 메모리) |
| 500F~1000F | 12.0 → 40.0 | Rare 40% / Epic 40% / Mythic 18% / Legendary 2% | Sp06+ MythicEssence 소비처 + Legendary Power Sp06+ 도입 정합 |
| 1000F+ | 정지 권장 (절차 생성 미도입) | — | Sp09 분기 결정 (`project_sp06_plus_lever_decisions.md`) 종료 후 v3.0 발주 |

### 무한 곡선 설계 원칙 (Sp06+ 박세린 Sp별도 발주 영역)

- **속성 4종 + 저항 4종** (Sp07 신규): 500F+ 구간에서 속성 매칭 보너스 / 페널티 ×1.3 / ×0.7
- **드롭 로그**: 무한 모드 = `project_sprint03_idle_research.md` 5대 결정 정합 (드롭 로그만 / 자동 PP / 층 고정)
- **시즌 패스 연동**: 무한 모드 100F 단위 마일스톤 = 시즌 패스 Tier 보상 (`project_volume2_synopsis_v2_decisions.md` v2.4 Tier 60/70/75/90)

## 5. 게임 디자인 측 팀 필요성 (소/중/대)

### 권장: **소 (1인 박세린 단독 유지)**

**근거**:

| 영역 | 박세린 단독 가능? | 근거 |
|------|----------------|------|
| 시나리오 트리거 120건 (1F~50F) | YES | `project_volume2_synopsis_v2_decisions.md` v2.4 매핑 표 그대로 흡수. 화당 ~30분 = 50화 × 30분 = 25h (Sp별도 발주 5건 분할) |
| 무한 곡선 51F~1000F 신규 | YES | Sp06~09 (`project_phase_2_3_roadmap_v2_decisions.md` 9주 / 2026-07-20~09-14) 영역. 신규 발주 0 |
| 강시연 본문 통합 (10화 = 100,000자+) | YES | `feedback_writer_collaboration_protocol.md` 1주 2화 / 24~48h 회신 protocol 그대로 |
| 강시연 신규 챕터 (chapter_18~50) | NO (강시연 단독) | 박세린 = 검수 라인. 작성 X |
| 게임 측 트리거 구현 (Unity / 웹) | NO (구현 측 영역) | code-lead / web-game-lead 영역 (Tier 2 Lead 신규 채용 권장) |

**중(2~3) 또는 대(4~5) 채용 시 박세린 권장 비권장 사유**:
- 박세린 분업 부담 = 현재 GDD + 5 sprint 동시 ≠ 게임 디자인 신규 인력 필요. **구현 측 인력 부담** (web-game-lead + 가능하면 unity-game-lead).
- 메모리 `project_web_lead_recruitment.md` 패턴 (web-lead 김민준 1인 채용으로 D+5에 24 산출물 / -88% 효율) 재현 권장.
- 시나리오 트리거 / 밸런스 / 수치 = 박세린 1인이 가장 빠름 (분업 시 정합성 손상 위험 = `project_milestone_bonus_pct_pp_only_lock.md` 단일 곱 경로 잠금 정합 사상).

**결론**: **게임 디자인 측 = 박세린 단독 / 신규 채용 = 구현 측 (web-game-lead 1인 = 김민준 산하 흡수 또는 별도 신설)**.

## 7. 확실하지 않은 가정 1~2건 (PD 검토 없이 잠기므로 위험 헷지)

1. **#7 D+180 = 웹게임 MVP가 강시연 chapter_18~50 33화 작성 완료를 전제** = 강시연 1주 2화 protocol 시 33화 / 2 = 17주 ≈ 4개월. **risk**: 강시연 회신 24~48h 초과 시 D+180 슬립. **헷지**: 50F를 1차 MVP 임계로 낮추되, 본문 50화 부재 시 25F (1권 17화 + 8화 보강)으로 자동 다운그레이드. PD 별도 결정 없으면 박세린 단독 판정.
2. **#5 1000F 정지 권장 = Sp09 분기 (Follower / 속성 / 수호자 택1) 결정 전 절차 생성 미도입**. **risk**: 글로벌 모바일 RPG 무한 모드 1000F 한계 = 디아블로 4 Torment 4 진입 어려움 패턴 = 코어 유저 이탈 가능. **헷지**: 1000F 도달 = 시즌 패스 Tier 100 (영원의 증표) 보상 + 시즌 리셋 시 1F 재시작 (`project_sprint05_season_research.md` 7대 결정 시즌 50% retain 정합).
