## 5. 강시연 윤문 우선순위 (D+15 가속 정책)

- **메모리 정합**: `feedback_writer_collaboration_protocol.md` 1주 2화 페이스 + 24~48h(최대 72h) 회신 + PD "페이스 자유 채택" 천명.
- **D+15 (2026-05-19) 윤문 진행도 추정**: 채용 D+0 (5/2) ~ D+15 = 약 2.5주 = **5화 윤문 가능** (1주 2화 페이스).
- **우선순위**:
  1. 1권 chapter_00~04 (1F~3F 매핑) — D+15 출시 직후 1F 진입 사용자 첫인상
  2. 1권 chapter_05~09 (4F~5F) — 김해 / 광복동 핵심 장면
  3. 1권 chapter_10~17 (6F~10F) — 부산 도입 / 1권 클라
  4. 2권 chapter_01~10 (11F~14F) — 무당9 도입
  5. 나머지 2권 + future 4화 — D+15 이후 사후 갱신
- **D+15 출시 시점 정책**: 강시연 윤문 미완 챕터는 **PD 본문 default 발행** + 강시연 사후 윤문 갱신 (rex-dialogue 텍스트 hot-swap, 차도윤 wire-up 영역).

## 6. 위험 가정 2건 (갱신)

1. **강시연 윤문 18화 미완 = D+15 출시 시점 1권 일부만 윤문 적용** — 추정 5화 윤문 가능 + 13화 default 발행. 메모리 `feedback_writer_collaboration_protocol.md` 1주 2화 페이스 정합 (PD 페이스 자유 채택). **사후 갱신 정책으로 D+15 발행 자체 영향 0** (default 발행으로 사용자 컷씬 비어있음 회피).
2. **2권 chapter_15 + 16/17 + 미래 4화 일부 강시연 작성 진행 중** = 18F~20F 트리거 30% 채움 + 무한 200F·400F·500F 3건 사전 발췌만. **나머지 17건 무한 보스 트리거는 6~9권 강시연 진행 페이스 의존 후속 발행**. 박세린(PM) D+15 직후 7차+1차 (D+45) 발주 시 윤서아 갱신 분량 보고 의무.
