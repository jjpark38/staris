3. 우리 무한던전과의 차별점 3건

  1. 싱글+방치 전환 — 원본은 파티4인 풀액티브 5분 레이드. 우리는 1인 자동전투 24h 방치. DPS 체감 -40% 가정 → 보스 HP 동일 두고 프레스티지로 보정 (Q1 C안). 원본 임포트 0% 수정 + 플레이어쪽 무한 성장축 신설로 해결.
  2. 드롭 모델 하이브리드 — 원본은 매 클리어마다 개별 드롭(파티 4인이 즉시 분배). 우리는 24h 방치 시 로그 폭발 → Q2 C안: Epic 이상 개별 보존 + Common~Rare 누적 요약. 디아블로 감성 + 모바일 UI 부담 동시 해결.
  3. 6등급 + Mythic 신규 — 원본은 4등급 Unique까지. 우리는 디아블로 시즌 프라이말 감성 + 셋 효과를 Mythic 1등급으로 흡수해 6단계 (Q3). 원본 Rare → 우리 Epic으로 리매핑 (GradeRemap.cs로 흡수).
