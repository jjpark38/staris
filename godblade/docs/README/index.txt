<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">3. 문서 구조 (정규 템플릿)</h2>

<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">제목 + 기간 (<code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light"># Sprint NN (YYYY-MM-DD ~ YYYY-MM-DD)</code>)</li><li class="mb-1">한 줄 맥락 (Phase 단계 + 이전 스프린트 연결 고리)</li><li class="mb-1"><strong class="font-semibold text-text-0">이월 후보 블록</strong> (Sprint 01부터) — 이전 스프린트 미완 항목 원문 복사 + <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">[from Sprint NN-1]</code> 태그</li><li class="mb-1"><strong class="font-semibold text-text-0">목표 (최대 3줄)</strong></li><li class="mb-1"><strong class="font-semibold text-text-0">작업 (TodoWrite 초기 리스트)</strong> — 체크박스 + 담당자 + 공수</li><li class="mb-1"><strong class="font-semibold text-text-0">의존성</strong> — &quot;A 없으면 B 못 함&quot; 순차 그래프</li><li class="mb-1"><strong class="font-semibold text-text-0">리스크 (최대 3건)</strong> — 대응책 포함</li></ol>
<h3 class="mb-2 mt-5 text-[15px] font-semibold text-text-0">종료 섹션 (D+14 작성)</h3>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1"><strong class="font-semibold text-text-0">완료</strong> — 체크된 작업 요약</li><li class="mb-1"><strong class="font-semibold text-text-0">미완 / 이월</strong> — 다음 스프린트 상단으로 복사할 항목</li><li class="mb-1"><strong class="font-semibold text-text-0">회고</strong> — 잘됨 / 안됨 / 다음 액션</li><li class="mb-1"><strong class="font-semibold text-text-0">D+14 체크리스트</strong> — 종료일에 실제 확인할 항목 (킥오프 시 미리 선예약)</li></ol>

<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">4. 책임 분담</h2>
