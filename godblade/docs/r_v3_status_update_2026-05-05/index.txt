## §2 회복 근거 상세

### 2.1 R-V3-1 Yellow → Green (정현우 Unity 모멘텀)

**v3.0 가정**: Sp02~Sp05 PAUSE 4개월 (5/18~9/15) = 정현우 Unity 모멘텀 손실 위험.

**5/5 회복 근거**:
1. Sp01 W2 13파일 정적 완료 (메모리 `project_volume1_chapter_21_30_paste_2026-05-05.md`) = Unity Importer baseline 확보
2. FlatBuffer D+14 (5/18) 3자 합의 슬롯 박힘 (메모리 `project_flatbuffer_self_build_decision_2026-05-04.md`) = 정현우 50h Self-build 슬롯
3. Sp-W04~W06 (Sp-W01~W08 중간) 부분 참여 슬롯 = 웹게임 FlatBuffer / glTF export 영역 협업

**잔존 가정**: 9/15 Sp02 재개 시점 1주 워밍업 (9/15~9/22) 권장.

### 2.2 R-V3-3 Yellow → Green (시나리오 진행)

**v3.0 가정**: D+30 7차 출시 = 권1 1~10화 minimum 入稿 / 강시연 33화 작성 전제.

**5/5 회복 근거**:
1. 권1 33화 누적 (chapter_00~20 + 21~30 + 39 + 50) = 60% 진행
2. D+25 마감 (1~10화 minimum) = 33화 누적 ≫ 10화 = 23화 여유 PASS
3. 1주 2화 페이스 (메모리 `feedback_writer_collaboration_protocol.md`) = 권1 잔여 22화 / 11주 = D+78 권1 完 추정
4. PD 페이스 자유 (메모리 v1.3 #4) 보존

**잔존 가정**: PD 본업 병행 10~15h/주 가정 슬립 시 권1 完 D+78 → D+90+ 가능. R-V3-3 재 Yellow 가능.

### 2.3 R-V3-4 Red → Yellow (웹게임 출시 시나리오 전제)

**v3.0 가정**: 웹게임 1차 출시 (D+105 = 2026-09-01, 메모리 `project_phase_2_3_roadmap_v3_0.md` §일정) = 강시연 33화 작성 전제 / 미달 시 50F→25F 자동 다운그레이드 헷지.

**5/5 회복 근거**:
1. D+0 누적 33화 ≥ 25화 = 25F 헷지 발동선 통과
2. D+105 추정 진행 = 33+(105-0)/3.5=63화 (1주 2화 페이스) = 50F 충분 통과
3. 50F 발동선 (50화) D+0+(50-33)*3.5=D+59 (2026-07-04) 추정 = D+105 출시 PASS

**잔존 가정**: PD 페이스 슬립 시 D+105 50화 미달 가능 (D+105 = 33+(105/3.5)=63화 추정 vs 슬립 시 33+(105-30)/3.5=54화). 50F 헷지 발동 가능성 잠재.
