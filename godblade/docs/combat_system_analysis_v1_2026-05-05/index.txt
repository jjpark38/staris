<pre class="my-4 overflow-x-auto rounded border border-border bg-bg-1 p-4 text-[13px]"><code>Skill
├─ owner: EodEntity
├─ data: GameDatascript.Skill (CSV → SO)
├─ eventList: List&lt;TimeEvent&gt;  ← TimeEvent 패턴 핵심
├─ cooldownTime / cooldownTimeMax
├─ autoCoolTime  ← 오토 모드 같은 스킬 연속 방지
├─ attackSpeedRatio  ← 공속 (Ability.AttackRatio × TimeCtrlSpeed)
├─ subSkillStartCheck / subSkillUseTiming  ← 서브 스킬 (메인 → 서브 콤보 3초 안)
├─ Stop() / Resume() / InitializeSKill() / Update() / BuildSkillEventLists()
└─ ApplyCooldownTime()  ← SkillLevelUseData 테이블에서 baseCoolTime + 쿨감 % 적용</code></pre>
<p class="mb-3 text-text-0"><strong class="font-semibold text-text-0">핵심 패턴</strong>:</p>
