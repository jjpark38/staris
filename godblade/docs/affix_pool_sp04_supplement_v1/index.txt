### 2.2 200F 약 4.20배 영향 추산 (정식 락, v1.3)

기존 30개 어픽스 평균 slot_weight = 100 가정. 5건 추가 (v1.2) 시:

```
v1.2 = 35어픽스 평균 slot_weight = 96.4
v1.3 = G-3.6 1건 추가 (slot_weight = 70)
       36어픽스 평균 slot_weight = (35×96.4 + 70) / 36 = (3374 + 70) / 36 = 95.7

영향 (v1.3 추가):
- B04 표준 빌드 (Epic 6슬롯) 에서 G-3.6 출현 확률 = 70 / 36×95.7 = 2.03%
- 즉 6슬롯 중 약 0.12슬롯이 G-3.6 (기댓값)
- G-3.6 평균 % 보너스 (Rare Epic 평균) ≈ 7-13% (광역 디버프 저항 = 데미지 출력 미공헌)

- B04 어픽스 1.83 → 약 1.82배 (-0.2%)
- B04 프레스티지 × 어픽스 = 2.30 × 1.82 = 약 4.19~4.20배 (v1.2 4.21배 대비 -0.2%)
- 200F 격파 타겟 38배 대비 = 1.65배 (v1.2 1.66배 대비 -0.01배)
```

**해석**: 200F 격파 약 4.20배 정식 (v1.0 대비 -1.4%). 타겟 1.7배 여유 → 1.65배 여유로 거의 변화 없음. **B08~B09 Mythic 폭주 재시뮬 = Sp04 W1 game-designer 선행 책임 정식 등록 (36어픽스 정합)**.
