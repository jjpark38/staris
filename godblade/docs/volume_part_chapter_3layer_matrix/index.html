§4 chapter_NN 라벨 정합성 검증 (3층 vs 1층 충돌)

4.1 chapter_NN ≠ 권 내 화수 (충돌)

본문 24화 "1부 完" 메타 = 25화부터 2부 1화 시작. 그러나 chapter_NN 라벨은 권 내 연속 = chapter_25 = 권1 26번째 화 (chapter_00 시작). chapter_NN ≠ 부 내 화수.

4.2 해결 = chapter_NN = 권 내 화수 단일 의미

  • chapter_00 = 권1 1번째 화 (프롤로그)
  • chapter_NN = 권1 (NN+1) 번째 화
  • 부 라벨 = chapter frontmatter part: 1 또는 part: 2로 별도 박힘 (강시연 자율)
  • 권 라벨 = chapter frontmatter volume: 1 (강시연 자율 + 김민준 D+15 mv 슬롯)
