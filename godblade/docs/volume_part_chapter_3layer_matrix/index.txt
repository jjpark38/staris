## §4 chapter_NN 라벨 정합성 검증 (3층 vs 1층 충돌)

### 4.1 chapter_NN ≠ 권 내 화수 (충돌)

본문 24화 "1부 完" 메타 = 25화부터 2부 1화 시작. 그러나 chapter_NN 라벨은 권 내 연속 = chapter_25 = 권1 26번째 화 (chapter_00 시작). **chapter_NN ≠ 부 내 화수**.

### 4.2 해결 = chapter_NN = 권 내 화수 단일 의미

- chapter_00 = 권1 1번째 화 (프롤로그)
- chapter_NN = 권1 (NN+1) 번째 화
- 부 라벨 = chapter frontmatter `part: 1` 또는 `part: 2`로 별도 박힘 (강시연 자율)
- 권 라벨 = chapter frontmatter `volume: 1` (강시연 자율 + 김민준 D+15 mv 슬롯)

### 4.3 chapter_39 / chapter_50 정합 (volume_2/ → volume_1/ 이동 슬롯)

| chapter | frontmatter `volume` | 파일 위치 (현재) | 김민준 mv 슬롯 |
|---------|---------------------|-----------------|--------------|
| chapter_39 | volume:1 | volume_2/ | D+15 mv → volume_1/ |
| chapter_50 | volume:1 | volume_2/ | D+15 mv → volume_1/ |
| chapter_18·19·20·41·49 | volume:1 | volume_2/ | D+15 mv → volume_1/ |

> 7건 mv 일괄 발주 슬롯 = 메모리 `project_chapter_folder_relocation_kim_minjun_followup.md`. IP 본문 우선 원칙 (메모리 `feedback_ip_sourcing_priority.md`) → 파일 이동 default.

## §6 라벨 사용 가이드 (강시연 / 윤서아 / 김민준 발주 시)

### 강시연 발주
- frontmatter `volume:N / part:N / chapter_in_part:N` 3층 박기
- 부 전환 시 본문에 "[제N부 完] / [제N+1부 시작]" 명시 (24화 패턴 default)
- chapter_NN 라벨은 강시연 자율 / 권 라벨은 자율 (frontmatter)

### 윤서아 발주
- 게임 트리거 v1.2 정정 (메모리 `project_yoonseoa_v1_1_chapter_remap_2026-05-04.md`) = chapter_NN frontmatter `volume:N` + `part:N` 2층 인용
- 시즌 메타플롯 = 부 단위 매핑 (1부=시즌1 / 2부=시즌2 default)

### 김민준 발주
- chapter mv 7건 = D+15 일괄 (메모리 `project_chapter_folder_relocation_kim_minjun_followup.md`)
- 웹사이트 `/novel` 라우트 = 권/부/화 3층 사이드바 박기 (D+30 7차 출시 시 wire-up)
