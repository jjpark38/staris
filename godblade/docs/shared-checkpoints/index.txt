## §1 목적 & 사용법

1. **목적**: 3개 설계 문서가 각자 보유한 체크리스트의 공통 항목을 합쳐, 스프린트별로 재활용 가능한 마스터 목록 1쪽 유지.
2. **사용법**: 각 스프린트 PR 제출 전 **§3 해당 스프린트 서브셋** 표를 보고 항목별로 자체 체크. 미통과 항목 있으면 PR 올리지 말 것.
3. **확장 원칙**: 신규 스프린트 추가 시 본 문서 §2 마스터 리스트에만 **확장**. 설계 문서에 체크리스트 복제 금지.
4. **(v1.1 추가)** **운영 체크포인트** (CP-M24~) 는 코드 PR 게이트가 아닌 **PM 운영 자체 체크** — 스프린트 D-7/D+14 시점에 PM이 적용.
