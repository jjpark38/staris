목적

Sp07 실 킥오프(2026-11) 7개월 전에, D2 결정 "4속성 D2 표준"의 수치·구조 선행 정리. Sp06 기존 이월 5건 소화 중에 Sp07 스펙 확정 지연으로 공수 초과되지 않도록 버퍼 기간 1쪽 메모로 예약.

본 메모는 수치 확정이 아니라 선행 정리. Sp07 킥오프 D-1에 game-designer가 본 메모를 입력으로 sprint-07-skill-element-spec.md 스펙 초안 작성.

1. 4속성 확정 (D2 계승)

속성영문stat_key (어픽스/프레스티지)몬스터 저항 수치 범위 (0~100)특수 효과 (Sp07 W2 검토)
화염FirefireDmgPct / fireResistPct0 ~ 100지속 피해 (3초 DoT) — Sp09+
냉기ColdcoldDmgPct / coldResistPct0 ~ 100이속 -30% 슬로우 (2초) — Sp09+
번개LightninglightningDmgPct / lightningResistPct0 ~ 100무작위 분산 데미지(40~160%) — Sp09+
독PoisonpoisonDmgPct / poisonResistPct0 ~ 100지속 피해 (5초 DoT, 총량 150%) — Sp09+

D2 감성:

  • 각 속성 저항은 0~100 범위. 기본치 = 0. 저항 캡 = 75 (디아블로 2 표준).
  • 무한던전 10층마다 몬스터 원소 저항 로테이션 (10층=Fire30 / 20층=Cold30 / 30층=Lightning30 / 40층=Poison30 / 50층=None(저항 리셋) / 60층부터 2원소 혼합 등).
  • 플레이어 저항 계산: 피해량 × (1 − clamp(저항 − 몬스터관통, 0, 75) / 100).

특수 효과 (DoT/슬로우/분산)는 Sp07 범위 제외. Sp09+ 확장 예약. Sp07 MVP는 순수 속성 피해/저항 곱연산만 구현.

2. 기존 데이터 재사용 훅 (3건)

Sp01~05 APPROVED 자산에 이미 속성 훅이 선반영되어 있어 Sp07 풀 비용이 최소화된다:

2.1 어픽스 elementalDmgPct (1슬롯 → 4슬롯 내부 분기)

  • designs/affix_pool.tsv Offensive 13개 중 elementalDmgPct 1건 존재 (tier 1~6 수치 기반).
  • Sp07 확장: 어픽스 30개 유지(항목 추가 금지). 내부적으로 elementalDmgPct 롤 시 서브타입 4종(Fire/Cold/Lightning/Poison)을 동시에 롤하여 서브 어픽스로 분기. UI 표기: "화염 피해 +12%" 형태.
  • Importer 변경점: AffixDefinitionSO 에 elementSubType : ElementType? 필드 옵셔널 추가 (None = 속성 없음 어픽스 / Fire/Cold/Lightning/Poison = 속성 롤).
  • 어픽스 30 → 내부 슬롯 분기로 유효 어픽스 풀 33개 효과.

2.2 프레스티지 Offense 탭 #7 (item_id=6) "원소 피해" (1항목 → 4항목 분기)

  • designs/prestige_items.tsv Offense 탭 10항목 중 1-indexed 7번째 / item_id=6 = "원소 피해" (stat_key: ElementalDamagePct, Lv30 상한 +60%). ※ 표기 규약: 본 메모는 "탭 내 1-indexed 순번(#7)"과 "TSV item_id 컬럼 값(item_id=6)" 두 가지 병기. sp07-resistance-formula-draft.md v0.1 DRAFT 는 item_id=6 기준.
  • Sp07 확장: 항목 1개 유지. 단 내부적으로 ElementalDmgPct 1항목 → 화염/냉기/번개/독 4항목으로 분할. 공수 없이 표시만 4탭 아코디언 — 총 30항목 골격 불변.
  • 대안: ElementalDmgPct 1항목 유지 + 캐릭터 선택 속성 1개에만 적용 (Sp07 UI 결정 유예 항목).

2.3 Mythic 드롭 테이블 (저항 옵션 슬롯 예약)

4. 계산식 (Sp02 Calculator 시그니처 불변 재확인)

속성 도입이 CalculateLevel / CalculateBonus 시그니처를 깨지 않도록 BuildSummary 확장만으로 흡수:

public struct BuildSummary {
    public double IdleRateMul;
    public double GoldMul;
    public double ExpMul;
    public double DropMul;
    // Sp07 신규 — 속성별 피해·저항 4쌍 8필드
    public float FireDmgPct;     public float FireResistPct;
    public float ColdDmgPct;     public float ColdResistPct;
    public float LightningDmgPct; public float LightningResistPct;
    public float PoisonDmgPct;   public float PoisonResistPct;
}

제약:

  • Calculator 코드 수정 0 (Sp04 어픽스 도입 시 확립된 규약 준수)
  • Importer 가 어픽스·프레스티지 입력 → BuildSummary 에 속성 4쌍 합산만 담당
  • 전투 계산 호출부: damage *= (1 + buildSummary.FireDmgPct); 4속성 분기 스위치

5. 200F 역산 검증 재진행 (Sp07 W2 필수)

Sp04 어픽스 풀은 "200F 격파 4.26배" 통과. Sp07 속성 도입 후 동일 역산 재검증:

  • 속성 저항 75% 몬스터 vs 속성 피해 +60% 빌드 = 실효 피해 0.25 × 1.60 = 0.40배 (저항 없는 무속성 대비 60% 감소)
  • 무속성 대비 빌드: 4.26배 유지 (속성 개입 없음)
  • 속성 특화 빌드 (저항 0 몬스터 + 속성 피해 60% 풀): 4.26 × 1.60 = 6.82배 (과성장)
  • 속성 역저항 빌드 (저항 75% 몬스터): 4.26 × 0.40 = 1.70배 (정체 구간)

설계 의도: 속성 선택이 몬스터 로테이션 따라 전략적 교체 유도 (디아블로 2 "저항 맵 Infinity Runeword" 감성). 빌드 다양성 레버리지 확보.

Sp07 W2 실측 후 속성 피해 상한치(프레스티지 60% / 어픽스 tier 6 15%) 재조정 여지. game-designer 판정.
