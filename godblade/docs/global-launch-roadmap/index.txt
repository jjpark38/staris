<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 1 — 현황 파악 (2~4주)</h2>
<p class="mb-3 text-text-0">10년 전 코드를 다시 이해하는 단계. 한 번에 다 보려 하지 말고 &quot;지도&quot;부터.</p>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">클라이언트 Unity 버전 확인 (<code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">ProjectSettings/ProjectVersion.txt</code>)</li><li class="mb-1">디렉토리 구조 한 페이지 요약</li><li class="mb-1">주요 게임 시스템 인벤토리 (전투/인벤토리/퀘스트/스킬 등)</li><li class="mb-1">서버 15개 역할 분류 (싱글에 필요 / 폐기 / 일부 흡수)</li><li class="mb-1">DB 스키마 카테고리별 분류</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 1 결과물</strong>: <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">GodBlade_현황지도.md</code> (폴더에 저장)</li></ol>
<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 2 — 싱글 전용 설계 재정립 (2~3주)</h2>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">멀티/온라인 종속 시스템 폐기 목록 확정 (PvP, 길드, 파티, 거래, 채팅 등)</li><li class="mb-1">싱글 플레이용 콘텐츠 볼륨 결정 (메인 스토리 X시간, 사이드 X개)</li><li class="mb-1">진행 구조 재설계 (오픈월드 / 챕터 / 스테이지)</li><li class="mb-1">글로벌 시장 호환성 점검 (캐릭터/스토리/UI가 서구권에 통하는지)</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 2 결과물</strong>: <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">GodBlade_싱글GDD_v1.md</code></li></ol>
<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 3 — Unity 6 LTS 마이그레이션 (2~4개월)</h2>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">Unity 6 LTS 신규 프로젝트 생성 (별도 폴더, 원본은 그대로 보존)</li><li class="mb-1">의존성 패키지 정리 (UniRx → UniTask 등 모던 대체)</li><li class="mb-1">에셋 단계적 import (텍스처/모델/사운드 → 셰이더 → 프리팹 → 씬)</li><li class="mb-1">URP(Universal Render Pipeline)로 셰이더 마이그레이션</li><li class="mb-1">구 API 일괄 업데이트 (<code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">OnLevelWasLoaded</code>, <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">WWW</code>, 구 Input 등)</li><li class="mb-1">메인 씬 1개 동작 복구 → 점진 확장</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 3 결과물</strong>: Unity 6에서 메인 씬 + 1개 전투 씬 동작</li></ol>
<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 4 — 싱글 로직 리빌드 (3~6개월)</h2>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">서버에서 처리하던 전투 검증 → 클라 ScriptableObject + 매니저</li><li class="mb-1">인벤토리/장비/성장 → 로컬 데이터 모델</li><li class="mb-1">퀘스트/대화 → 데이터 드리븐 시스템 (가능하면 Yarn Spinner 등)</li><li class="mb-1">세이브 시스템 (로컬: <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">Application.persistentDataPath</code> + 무결성 해시)</li><li class="mb-1">밸런스 데이터를 ScriptableObject 또는 CSV로 분리</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 4 결과물</strong>: 처음~중간 보스까지 싱글 플레이 가능</li></ol>
<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 5 — 최소 백엔드 구축 (2~4주)</h2>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">Firebase vs Supabase 결정 (기본 추천: Firebase — 모바일 통합 쉬움)</li><li class="mb-1">인증: 구글/애플/스팀 계정 연동</li><li class="mb-1">클라우드 세이브 (자동 동기화 + 충돌 해결 정책)</li><li class="mb-1">글로벌 랭킹 (스피드런 / 점수 / 업적)</li><li class="mb-1">원격 설정 (Remote Config) — 밸런스 핫픽스용</li><li class="mb-1">기존 C# 서버 15개는 <code class="rounded bg-bg-3 px-1.5 py-0.5 font-mono text-[12px] text-gold-light">_archive_2021/</code>로 이동 (히스토리 보존)</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 5 결과물</strong>: 동작하는 클라우드 세이브 + 1개 랭킹 보드</li></ol>
<h2 class="mb-3 mt-6 text-[18px] font-semibold text-gold-light">Phase 6 — 로컬라이제이션 &amp; 폴리싱 (2~3개월)</h2>
<ol class="mb-3 ml-5 list-decimal text-text-0"><li class="mb-1">Unity Localization 패키지 셋업 (StringTable / AssetTable)</li><li class="mb-1">모든 하드코딩 텍스트 → 키 기반 추출</li><li class="mb-1">1차 번역 (영어 — 전문 번역가 또는 LLM 기반 + 네이티브 검수)</li><li class="mb-1">2차 번역 (중국어 간체, 일본어, 스페인어 — 매출 비중 큰 순)</li><li class="mb-1">폰트: 다국어 폰트 (Noto Sans 계열) + CJK 별도 폰트</li><li class="mb-1">UI 레이아웃: 영문이 한국어보다 1.5배 길어지는 문제 대응</li><li class="mb-1">QA: 각 언어별 글자 깨짐, 잘림, 줄바꿈 체크</li><li class="mb-1"><strong class="font-semibold text-text-0">Phase 6 결과물</strong>: 5개 언어 완전 로컬라이즈된 빌드</li></ol>
