GodBlade (Eternal Guardians) 글로벌 출시 로드맵

작성일: 2026-04-20 목표: 10년 전 멀티 RPG → 최신 Unity 6 + 싱글 플레이어 + 글로벌 출시 체제: 1인 파트타임 (본업 병행) 예상 총 기간: 약 24~30개월

핵심 전략 결정 사항

항목결정
타겟 플랫폼PC (Steam) + 모바일 (iOS/Android)
개발 체제1인 파트타임
온라인 범위최소 백엔드 (클라우드 세이브 + 글로벌 랭킹)
수익 모델Steam: 유료 / 모바일: 유료 + 광고
게임 모드싱글 플레이어 중심
1차 출시 언어한국어, 영어, 중국어 간체, 일본어, 스페인어

Phase 1 — 현황 파악 (2~4주)

10년 전 코드를 다시 이해하는 단계. 한 번에 다 보려 하지 말고 "지도"부터.

  1. 클라이언트 Unity 버전 확인 (ProjectSettings/ProjectVersion.txt)
  2. 디렉토리 구조 한 페이지 요약
  3. 주요 게임 시스템 인벤토리 (전투/인벤토리/퀘스트/스킬 등)
  4. 서버 15개 역할 분류 (싱글에 필요 / 폐기 / 일부 흡수)
  5. DB 스키마 카테고리별 분류
  6. Phase 1 결과물: GodBlade_현황지도.md (폴더에 저장)

Phase 2 — 싱글 전용 설계 재정립 (2~3주)

  1. 멀티/온라인 종속 시스템 폐기 목록 확정 (PvP, 길드, 파티, 거래, 채팅 등)
  2. 싱글 플레이용 콘텐츠 볼륨 결정 (메인 스토리 X시간, 사이드 X개)
  3. 진행 구조 재설계 (오픈월드 / 챕터 / 스테이지)
  4. 글로벌 시장 호환성 점검 (캐릭터/스토리/UI가 서구권에 통하는지)
  5. Phase 2 결과물: GodBlade_싱글GDD_v1.md

Phase 3 — Unity 6 LTS 마이그레이션 (2~4개월)

  1. Unity 6 LTS 신규 프로젝트 생성 (별도 폴더, 원본은 그대로 보존)
  2. 의존성 패키지 정리 (UniRx → UniTask 등 모던 대체)
  3. 에셋 단계적 import (텍스처/모델/사운드 → 셰이더 → 프리팹 → 씬)
  4. URP(Universal Render Pipeline)로 셰이더 마이그레이션
  5. 구 API 일괄 업데이트 (OnLevelWasLoaded, WWW, 구 Input 등)
  6. 메인 씬 1개 동작 복구 → 점진 확장
  7. Phase 3 결과물: Unity 6에서 메인 씬 + 1개 전투 씬 동작

Phase 4 — 싱글 로직 리빌드 (3~6개월)

  1. 서버에서 처리하던 전투 검증 → 클라 ScriptableObject + 매니저
  2. 인벤토리/장비/성장 → 로컬 데이터 모델
  3. 퀘스트/대화 → 데이터 드리븐 시스템 (가능하면 Yarn Spinner 등)
  4. 세이브 시스템 (로컬: Application.persistentDataPath + 무결성 해시)
  5. 밸런스 데이터를 ScriptableObject 또는 CSV로 분리
  6. Phase 4 결과물: 처음~중간 보스까지 싱글 플레이 가능

Phase 5 — 최소 백엔드 구축 (2~4주)

  1. Firebase vs Supabase 결정 (기본 추천: Firebase — 모바일 통합 쉬움)
  2. 인증: 구글/애플/스팀 계정 연동
  3. 클라우드 세이브 (자동 동기화 + 충돌 해결 정책)
  4. 글로벌 랭킹 (스피드런 / 점수 / 업적)
  5. 원격 설정 (Remote Config) — 밸런스 핫픽스용
  6. 기존 C# 서버 15개는 _archive_2021/로 이동 (히스토리 보존)
  7. Phase 5 결과물: 동작하는 클라우드 세이브 + 1개 랭킹 보드

Phase 6 — 로컬라이제이션 & 폴리싱 (2~3개월)

  1. Unity Localization 패키지 셋업 (StringTable / AssetTable)
  2. 모든 하드코딩 텍스트 → 키 기반 추출
  3. 1차 번역 (영어 — 전문 번역가 또는 LLM 기반 + 네이티브 검수)
  4. 2차 번역 (중국어 간체, 일본어, 스페인어 — 매출 비중 큰 순)
  5. 폰트: 다국어 폰트 (Noto Sans 계열) + CJK 별도 폰트
  6. UI 레이아웃: 영문이 한국어보다 1.5배 길어지는 문제 대응
  7. QA: 각 언어별 글자 깨짐, 잘림, 줄바꿈 체크
  8. Phase 6 결과물: 5개 언어 완전 로컬라이즈된 빌드

Phase 7 — 출시 & 마케팅 (1~2개월)

  1. Steam:
  • Steamworks 등록 ($100), 스토어 페이지 작성
  • Next Fest 체험판으로 위시리스트 확보 (가장 강력한 마케팅)
  • 트레일러, 스크린샷, 게임플레이 GIF
  1. 모바일:
  • 필리핀/캐나다 소프트런칭으로 리텐션/광고수익 측정
  • ASO (앱스토어 최적화) 키워드 연구
  • AdMob/Unity Ads 통합
  1. 공통:
  • 인디 인플루언서/스트리머 200명 리스트, 키 배포
  • Reddit r/IndieGaming, r/IndieDev 자연스러운 노출
  • Press Kit (presskit.com 같은 도구 활용)
  1. 출시 후:
  • 첫 7일 안의 리뷰/이슈 대응 → 핫픽스
  • 1~3개월차 첫 업데이트 (콘텐츠 추가, 이슈 정리)
