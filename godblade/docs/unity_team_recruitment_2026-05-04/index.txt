4:T19ae,# Unity 트랙 인력 충원 1쪽 분석 (정현우, 2026-05-04)

> 본 문서는 PD 명시 답변 없이 즉시 잠금되는 권장 default 일괄 채택 방식. 이의 시 PD 가 본문 ★ 표기 결정에 X 1회만 표시하면 옵션 매트릭스로 회귀.

## TL;DR (3줄)

1. **권장 default = 옵션 A (충원 0)**, 단 **2026-08-15 시점 재평가 트리거 1건** 박음 — Sp02 재개(2026-09-15) D-30 시점에 정현우+류재현 2인이 9~10월 회귀 부담을 실측한 후 재발주.
2. **Tier 한계 12 → 14 까지 2 슬롯 여유**. Unity 충원 1 + DB 통합 FlatBuffer Specialist 1 까지가 안전 상한. 그 이상은 PD 1인 오케스트레이션 부담 한계 초과.
3. **즉시 충원은 비추** — 2026-05-04~09-15 4개월 Unity 트랙은 Sp01 마무리(05-17) + 캐릭터 MVP 5체 PD 후속 검증 + 웹게임 데이터 공유 정합성 검토(주 ~3h)뿐. 정현우+류재현 2인으로 충분히 흡수 가능.

| 05-18~09-01 (웹게임 4M) | 주 ~2h FlatBuffer 합의 + 데이터 공유 검토 | 주 ~1h IAP 사전 조사 (Sp02 재개 대비) | 메인 트랙은 차도윤 |
| 09-15~12 (Sp02~05 재개) | 주 ~10h 풀로드 | 주 ~3h 광고 SDK 사전 작업 | Phase 4 본판 준비 |
| 2027-01~04 (Phase 4) | 풀로드 + 글로벌 출시 안정성 | 풀로드 + 멀티 플랫폼 SDK | **이 시점 충원 필요성 ★ 재평가** |

→ **2026-09-15 까지는 2인 안전권**. Phase 4 본판 진입 전 (2026-12) 1차 재평가 필수.

## 권장 default ★ + 근거

★ **옵션 A (충원 0) + FlatBuffer 외주 1회성 (~40h, 2026-05-15)** 일괄 잠금.

근거 4건:
1. **Tier 한계 잔여 슬롯 2 = 2026-12 Phase 4 본판 충원 보존** — 지금 풀팀 채용 시 Phase 4 본판 시점 Tier 14 초과로 PD 오케스트레이션 부담 폭발. 류재현 페르소나 ("리더가 결정 안 하면 폭발") + 정현우 페르소나 (까칠한 코드 품질 광) 2인 충돌 중재만으로도 PD 1인 한계 근접.
2. **2026-05~09 Unity 트랙 풀로드 부재** — 위 부담 실측표에서 정현우 주 ~2h, 류재현 주 ~1h 만으로 흡수 가능. 충원은 유휴 인력 비용.
3. **FlatBuffer 만 외주 1회 (~40h)** — 3자 합의 D+14 후 1회성 작업. 정규직 채용 시 출시 후 유지 부담 제로 = 비용 낭비. 외주 단가 정현우 시간단가 ×60% 가정 시 ROI 명확.
4. **Phase 4 본판 진입 시점(2026-12) 재평가 트리거 1건** — Unity QA + Animation Specialist 2 후보 중 실측 부담 기반 1건 선별. 9개월 후 재평가는 충분.

## Tier 14 한계 가정 + 검증

현 12 → 권장 적용 후 13 (FlatBuffer 외주 = agent 카운트 X) → Phase 4 진입 시 14 (Unity QA 1 추가). **14 가 안전 상한**:

- PD 1세션 컨텍스트 윈도우 = 12~14 agent JD + 메모리 ~50건 + 로드맵 = ~80% 토큰 소진 추정.
- 14 초과 시 PD 가 agent 호출 결정 자체에 ~30분 소요 (현재 ~5분) — 1인 파트타임 일정 한계.
- 김민준(웹) + 차도윤(웹게임) 트랙 충원이 D+180 이전에 추가 발생 시 Unity 충원 우선순위 후순위로 자동 강등.

## Unity Sp02 재개(2026-09-15) 사전 발주 시점

- **2026-08-15 (D-30)**: PM 에게 Sp02~05 재개 부담 실측 발주 → 정현우+류재현 2인 부담 ≥ 70% 시 Unity QA 외주 1회성 (~30h) 추가 검토.
- **2026-12-01 (Phase 4 D-120)**: 정현우 + PM 합동 분석 → Unity QA / Animation Specialist 1건 선별 발주.

## 위험 가정 2건

1. **위험 1: 캐릭터 MVP 5체 PD 후속 검증(컴파일+Diagnose+Play) 회귀 5건+ 발생 시** — 정현우 본인이 1주 ~10h 흡수 시 Sp01 W2 마감(05-17) 지연 가능성. 헷지: 회귀 3건 초과 시 PM 에게 Sp01 W2 1주 연장 발주.
2. **위험 2: FlatBuffer 외주 채용 실패** (글로벌 시장 FlatBuffer 한국어 가능자 희소) → 2026-05-15 D+14 합의 지연 시 헷지: 정현우 + 차도윤 2인이 ~80h Self-build (Sp02 재개 일정 영향 0, 웹게임 트랙 1주 영향).

## 분업 인수인계 (dots-platform 류재현)

- 본 분석은 **Unity 트랙 충원 평가**만 다룸. 류재현 영역 (DOTS / 모바일 광고 / Steam SDK / IAP) 는 류재현 본인이 별도 발주 시 자체 충원 평가 가능.
- FlatBuffer 외주 결정 시 류재현 개입 0 (정현우 + 차도윤 + 한가영 3자 영역).
