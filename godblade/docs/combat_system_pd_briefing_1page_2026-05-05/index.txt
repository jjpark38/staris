4:T17a0,# PD 1쪽 브리핑 — 전투 시스템 분석 및 포팅 전략

**작성**: 정현우 (code-lead)
**수신**: PD (출장 복귀 시 인수)
**일자**: 2026-05-05

## 한 줄 결론

**GodBlade 전투 시스템은 Unity 6 으로 그대로 가져올 수 있다 (호환성 ~85%, A안 권고). 손맛 100% 보존 + 외부 의존 2건만 패치하면 99% 동작. Phase 4 (2027-04+) 진입 시 약 180h 소요.**

## 손맛은 무엇으로 만들어지는가 — 4중 레이어

| # | 메커니즘 | 위치 | 효과 |
|---|---------|------|------|
| 1 | **콤보 100 + 3초 리셋** | `EodEntityComboHitComponent.cs` (95 LOC) | 누적 타격감 (디아블로 4 콤보 게이지 류) |
| 2 | **카메라 흔들림 4 진입점** | Skill / Action / Projectile / 인라인 hitedShake → 모두 `EodCamera.Get.ShakeCamera()` 단일 수렴 | 타격 무게감 (직접 타격 / 투사체 충돌 / 스킬 발동 모두) |
| 3 | **Matrix Trail (좌/우 무기 궤적)** | `EodMatrixTrail.cs` (Xft.XWeaponTrail wrapper) | 베요네타류 무기 궤적 (sin 곡선 진동) |
| 4 | **잔상 복제 (모션 블러)** | `EodEntityMatrixEffectComponent.cs` (188 LOC, Animator 자체 N개 복제 + 0.1초 간격 순차 활성화) | 디아블로 4 잔상 효과 |

**스킬 시스템 = TimeEvent 기반 데이터 드리븐**:
- CSV → 9 테이블 → SkillEventBuilder 팩토리 → 13 SkillEvent 종류 (CreateProjectile / ShakeCamera / Move / Teleport / Rotate 등)
- Skill 인스턴스 = `List<TimeEvent>` (시간 기반 발화)
- 메인-서브 스킬 콤보 (3초 안 누르면 서브 발동, 디아블로 4 「2단 콤보 스킬」 류)
- 35 EventBase 발행-구독 + 오브젝트 풀 (GC 최소화) — 견고한 설계

## 보존 우선순위

| 순위 | 항목 | 보존도 | 위험 |
|------|------|--------|------|
| 1 | 카메라 흔들림 4 진입점 | 100% (단일 EodCamera 만 마이그레이션) | 낮 |
| 2 | 콤보 시스템 | 100% (95 LOC, drop-in) | 낮 |
| 3 | 13 SkillEvent + TimeEvent 패턴 | 100% (B안 재구현 시 95% → A안이 안전) | 중 |
| 4 | Matrix Trail (Xft) | **70% (Xft Unity 6 미보증, 대체 25h 작업)** | **중-높** |
| 5 | 잔상 복제 | 100% (Animator 의존만, 디버그 코드 제거 후) | 낮 |
| 6 | 35 EventBase | 100% (drop-in) | 낮 |

| B 비슷하게 | 240h | 6주 풀 / 12주 파트 | 80~95% | 2 | 비추 (일정 +3개월 + 손맛 미세 차이) |

- C: PD 지시 위배 + 장기 비용 더 큼

### D-2 — Xft 라이브러리 처리 (D-1 후)

- 외부 의존 제거 → 라이브 안정성 향상
- 대안: Xft 호환 PoC 1h 후 재평가 / Asset Store 대체 ($30~$50)

### D-3 — god 클래스 분할 시점 (D-1 A안 선택 시)
- 정현우 권고: **포팅 동시 분할** (Combat 2499 → 4 sub / Skill 1794 → 3 sub)
- 단일 작업 통합 → 총 비용 -10%
