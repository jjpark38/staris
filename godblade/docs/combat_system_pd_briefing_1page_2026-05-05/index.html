한 줄 결론

GodBlade 전투 시스템은 Unity 6 으로 그대로 가져올 수 있다 (호환성 ~85%, A안 권고). 손맛 100% 보존 + 외부 의존 2건만 패치하면 99% 동작. Phase 4 (2027-04+) 진입 시 약 180h 소요.

손맛은 무엇으로 만들어지는가 — 4중 레이어

#메커니즘위치효과
1콤보 100 + 3초 리셋EodEntityComboHitComponent.cs (95 LOC)누적 타격감 (디아블로 4 콤보 게이지 류)
2카메라 흔들림 4 진입점Skill / Action / Projectile / 인라인 hitedShake → 모두 EodCamera.Get.ShakeCamera() 단일 수렴타격 무게감 (직접 타격 / 투사체 충돌 / 스킬 발동 모두)
3Matrix Trail (좌/우 무기 궤적)EodMatrixTrail.cs (Xft.XWeaponTrail wrapper)베요네타류 무기 궤적 (sin 곡선 진동)
4잔상 복제 (모션 블러)EodEntityMatrixEffectComponent.cs (188 LOC, Animator 자체 N개 복제 + 0.1초 간격 순차 활성화)디아블로 4 잔상 효과

스킬 시스템 = TimeEvent 기반 데이터 드리븐:

  • CSV → 9 테이블 → SkillEventBuilder 팩토리 → 13 SkillEvent 종류 (CreateProjectile / ShakeCamera / Move / Teleport / Rotate 등)
  • Skill 인스턴스 = List<TimeEvent> (시간 기반 발화)
  • 메인-서브 스킬 콤보 (3초 안 누르면 서브 발동, 디아블로 4 「2단 콤보 스킬」 류)
  • 35 EventBase 발행-구독 + 오브젝트 풀 (GC 최소화) — 견고한 설계
